# v0.17.6 로그아웃 복구와 설문 응답 방식 명확화

- 로그아웃 POST 직전에 현재 CSRF 쿠키를 반영해 다른 탭 로그인 후 오래 열린 화면의 토큰 불일치를 예방합니다. 서버의 CSRF 검증은 유지합니다.
- 로그아웃 보안 검증 실패 시 새 토큰을 가진 확인 폼을 표시합니다. GET 로그아웃은 확인 화면만 열고 세션은 종료하지 않습니다.
- 보안 거절 원인은 허용된 분류명만 기록하며 토큰·쿠키·이메일·요청 내용은 기록하지 않습니다.
- 새 설문 질문은 단일 선택을 기본 제안합니다. 단일 선택/복수 선택 문구와 도움말을 명확히 구분합니다.
- 단일 선택은 라디오 버튼, 복수 선택은 체크박스로 응답합니다. 단일 선택에 여러 값을 보낸 요청은 서버에서 거절합니다.
- 이미 배포된 설문과 기존 답변은 일괄 변경하지 않습니다. DB 변경 없음.
