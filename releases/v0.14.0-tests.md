# Workhub v0.14.0 확인 가이드

## 설문조사 — 관리자 계정
1. 관리자 계정의 설문조사 > 설문 작성.
2. 제목·설명, 응답 시작/마감, 기명/익명, 직원 선택 대상을 지정합니다.
3. 하나 선택·여러 선택·자유 의견·1~5 만족도 질문을 추가합니다. 필수 여부를 정합니다.
4. 저장하고 검토 후 대상 확정하고 배포. 배포 뒤 질문과 대상은 고정됩니다.
5. 실제 메일 테스트는 본인 1명으로 지정하세요. 신규 설문은 이메일 안내가 기본이며 하이웍스 알림은 추가 선택합니다.
6. 설문 상세에서 제출 현황, 결과 확인에서 집계·개인별 답변(기명만)을 봅니다. 마감·기간 관리에서 마감 또는 연장.

## 설문 응답 — 직원 계정
1. 직원에게는 설문 메뉴가 표시되지 않습니다. 안내 메일의 설문 응답하기 버튼으로 들어갑니다. 대상이 아닌 설문 URL로 접근하면 차단됩니다.
2. 응답 기간 안에 임시 저장 후 다시 열어 내용이 남는지 확인합니다.
3. 필수 항목을 비우면 제출되지 않습니다. 정상 제출하면 완료 안내와 함께 재제출이 차단됩니다.
4. 익명 설문은 관리자의 결과 화면에 작성자별 응답이 나오지 않습니다. 참여 현황은 별도로 보입니다.
5. 제출한 직원은 이후 독려 대상에서 제외됩니다. 독려는 마감 3일/1일 전, 모든 안내 사이 최소 24시간 간격이며 중복 발송되지 않습니다. 빠르게 확인하려고 실제 서버 시간을 변경하지 마세요. 시간 조건은 자동 검사로 검증했습니다.

## 수행 평가 — 이상건 등 대표·본부장 직원 계정
1. 조직 현황 > 수행 평가. GUNSYSTEMS 시스템 관리자 계정에는 메뉴가 없고 직접 URL도 차단됩니다.
2. 평가 작성에서 본인을 제외한 대상 직원, 관련 업무(선택), 평가 기간을 지정합니다.
3. 다섯 항목을 1~5점 또는 평가 제외로 선택합니다. 관찰·평가 근거, 업무 상황과 저장·수정 사유를 기록합니다.
4. 작성 중 저장 / 평가 확정. 확정 후 수정하면 이전 기록과 사유가 보존됩니다.
5. 월별·분기별·연간 조회에서 평가 건수와 항목별 평균을 확인합니다. 업무별/기간 종합 평가를 합산하지 않습니다.
6. 평가 상세에서 배정 확인 시각·경과 시간, 기간 내 진행 보고, 개인 수행 완료 시각과 마감일을 참고합니다. 경과 시간은 휴일·휴가를 제외한 점수가 아닙니다.

## 모바일 확인
- 360/390/430px 폭에서 작성·응답·결과·평가 입력과 날짜 컨트롤을 확인합니다.
- PC 브라우저의 모바일 폭 검사는 실제 아이폰 Safari와 동일한 검증이 아닙니다. 실제 기기에서는 날짜 선택 후 정렬과 키보드 확대도 확인해 주세요.
