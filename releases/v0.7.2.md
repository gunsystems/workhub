# Workhub v0.7.2 직원 접근 확인 복구

2026-11-09 · Asia/Seoul

하이웍스 재직 확인 정보가 오래된 경우 업무 진입 시 제한된 재조회를 먼저 수행합니다. 인증 확인은 정기 업무 처리보다 먼저 실행합니다. 실제 조회 실패·퇴사·이메일/하이웍스 연결 불일치는 계속 차단합니다.

직원 등록 확인 HTML의 같은 출처 폼 전송을 허용해 재확인 및 로그아웃이 HTTPS CSRF 오류로 막히는 조건을 수정합니다. 오류 화면에서 재시도 링크로 들어온 GET은 POST 전용 주소의 405 오류 대신 대시보드로 돌아갑니다. 조회 변경은 여전히 CSRF 보호 POST로만 수행합니다.

- 신규 회귀 검사 7개: HTTPS 재확인 후 업무 등록 화면, 차단 화면 로그아웃, 오래된 캐시 재조회, 외부 API 실패 시 차단 유지, 외부 Origin 거부, 오류 복귀 GET, 정기 처리 실패 전 재직 조회.
- 검증: 전체 294개 검사 통과. 신규 7개 회귀 검사 포함.
- 배포: 대기. DB migration 없음.
- 상세 관측: investigations/2026-11-09-membership-retry.md.
