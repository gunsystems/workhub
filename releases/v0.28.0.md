# v0.28.0 · Workhub 공동 문서 파일 관리

- Workhub에서 파일 1개당 최대 20MB를 업로드합니다. PDF·Office·텍스트·이미지·ZIP을 지원하고 드래그 앤 드롭·선택 취소·전송 상태를 표시합니다.
- 파일 옆 메뉴에 다운로드·새 버전 업로드·이름 변경·같은 문서함 안에서 이동·휴지통 삭제를 추가합니다.
- 새 파일 등록은 같은 이름을 자동 덮어쓰지 않습니다. 새 버전 등록은 사용자가 명시적으로 선택하며 문서 ID·이름·업무 연결을 유지합니다.
- 모든 조회와 변경은 연결한 직원의 위임 토큰으로 실행하며, 사이트 범위와 실제 Microsoft 권한을 다시 확인합니다. 앱 토큰 대체나 새 Microsoft 권한 부여는 없습니다.
- 변경 확인은 사용자·대상·행위·목적지·eTag에 연결된 10분 일회용 확인과 CSRF를 사용합니다. 임의 대상 변경·오래된 확인·중복 제출을 차단합니다.
- 파일과 폴더의 생성·이름 변경·이동·휴지통 삭제, 파일 새 버전 등록 및 업무 연결은 관리자 시스템 로그에 처리자·시각·대상·변경 내용을 기록합니다. 파일 내용·인증 토큰·서명 URL은 로그에 남기지 않습니다.
- 일반 직원 화면에서 원본 저장소 관리 버튼을 제거합니다. 관리자에게는 저장소 관리 보조 링크를 유지합니다.

## 기록 범위

- Word·Excel 웹 편집기에서 저장한 본문 수정이나 SharePoint에서 직접 처리한 작업은 Workhub를 통과하지 않습니다. 현재 시스템 로그로 완전한 Microsoft 감사 이력을 제공한다고 표시하지 않습니다.
- 원본 저장소의 버전 이력과 Microsoft 감사 로그를 통합하는 작업은 별도 연동이며, 이번 배포에서 권한을 확대하지 않습니다.
- 삭제는 Microsoft 휴지통 이동이며 영구 삭제하지 않습니다. 휴지통 복원은 관리자에게 요청합니다. 폴더 관리는 기존 관리자·대표 권한과 빈 폴더 제한을 유지합니다.
- 문서 본문 편집은 기존 Word·Excel 등의 편집기로 연결합니다. 신규 Office 문서를 빈 템플릿에서 만드는 기능은 포함하지 않습니다.

## 검증

- 직원별 사이트 경계, CSRF·일회용 확인·변경 충돌·이동 대상 변조·확장자 유지·업로드 충돌·바이너리 직접 전송·원본 다운로드 바이트·토큰 비전달·관리자 로그를 자동 검사합니다.
- Linux 전체 회귀 검사 806개와 JavaScript 검사 10개 통과. 관련 검사 64개 통과.
- 대표 계정 실제 연결: 한글 PNG 업로드, 다운로드 SHA-256 원본 일치, 새 버전 저장(동일 문서 ID·이름), 이름 변경, 같은 문서함 루트 이동, 휴지통 이동 및 목록 정리 확인.
- 최초 uploadSession 요청이 실제 서비스에서 400을 반환하여 20MB 제한에 맞는 공식 바이너리 직접 전송 방식으로 수정. 무자동재시도·리디렉션 금지·신규 충돌 방지·기존 버전 If-Match 유지.
- PC 파일 메뉴가 화면 아래로 나가지 않도록 위로 열리게 정리. 관리자 로그 및 모바일 최종 확인은 이어서 기록합니다.
