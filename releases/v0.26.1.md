# v0.26.1 · 공동 문서 폴더 탐색·관리

- 폴더 아이콘·이름 클릭으로 이동, 현재 경로와 상위 폴더 이동 제공.
- 관리자·대표의 폴더 생성·이름 변경·빈 폴더 휴지통 이동 추가. Microsoft 본인 권한을 별도로 적용하며 서버 앱 토큰으로 우회하지 않음.
- 자료가 있는 폴더와 문서함 루트 삭제 차단. 확인 화면과 10분 만료·일회용 사용자별 서명, eTag 충돌 검사를 적용.
- 파일·폴더의 공유 권한 확인 패널. 반환된 공유 정보가 전체 유효 권한 목록과 같지 않음을 명시하고 SharePoint 원본 확인 경로 제공.
- 폴더 변경 시스템 로그·페이지 도움말·모바일 줄바꿈 보강.
- 사이트별 앱 권한이 아직 읽기인 경우 생성·이름 변경·삭제는 거부되며 조회는 유지. 별도 승인을 받아 Workhub 전용 사이트에 한해 쓰기 권한 설정 필요.

## 검증

- 공동 문서·연결 검사 41개 통과, 마이그레이션 변경 없음.
- 실제 폴더 변경 및 화면 확인은 배포와 사이트 쓰기 권한 설정 후 진행.
