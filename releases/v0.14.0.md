# Workhub v0.14.0 — 설문조사와 임원 수행 평가

설문조사를 알림 영역에 별도 배치합니다. 관리자 작성·검토·배포, 전사/부서/직원 대상 확정, 단일·복수 선택/주관식/만족도, 기명·익명, 임시 저장·제출·기간 마감/연장, 참여 현황과 집계를 지원합니다. 제출 후 응답 수정은 허용하지 않습니다. 익명 응답에는 직원 연결과 개별 제출 시각을 저장하지 않고 참여 기록의 임시 답변을 삭제합니다. 내용에 따른 재식별 가능성은 별도 안내합니다. 개인정보와 답변 내용을 일반 시스템 로그에 기록하지 않습니다.

최초 안내 및 미응답자 마감 3일 전/1일 전 안내. 최초 안내 후 최소 24시간 간격, 중복 키, 전송 직전 제출/마감/재직·인증 재검증, 모호한 응답 자동 재발송 금지. 이메일·하이웍스 채널 선택. 하이웍스 웹 접수와 모바일 푸시 수신은 구분합니다.

대표/본부장 직책의 활성 직원만 수행 평가를 작성·조회합니다. 시스템 관리자 권한만으로 평가 접근을 허용하지 않습니다. 본인 평가 불가, 타 임원 초안 조회와 평가 수정 차단. 업무별 또는 기간별 평가, 다섯 항목 1~5점/평가 제외, 관찰 근거·업무 상황·수정 사유 필수. 낙관적 버전 검사와 확정 이력 보존. 월/분기/연간 집계는 업무별과 기간 종합 평가를 분리하며 근거 건수와 단순 평균 표시. 자동 연봉 산정/직원 순위 없음. 관련 수행 기록은 참고 사실로 별도 표시합니다. 근무 시간·휴가를 자동 추정하거나 과거 점수를 소급 생성하지 않습니다.

기존 업무별 시스템 기록을 함께 조회합니다. 이번 버전은 자동 행동 점수의 새 가중치나 인사 처우 자동 결정을 구현하지 않습니다. 교육자료는 요청대로 최종 안정화 단계로 보류합니다.
