# Workhub v0.9.3 하이웍스 일정 연결 캡처 도움말

2026-11-09 · Asia/Seoul

- 실제 하이웍스 ‘외부 캘린더 구독하기’의 빈 설정창을 캡처해 추가. 직원·고객 일정/브라우저 탭/실제 연결 주소가 없는 설정창만 잘라 500×450 WebP로 보관.
- 본인 주소 발급/복사 → 내 캘린더 행에 마우스를 올려 ⊕ 클릭 → 외부 캘린더 구독하기 → URL·Workhub 이름·색상·알림 → 저장·체크·해당 날짜 확인을 안내.
- 연결 화면 본문, 페이지별 도움말, 전체 사용 가이드에 같은 안내 컴포넌트 사용. 화면 크기에 맞는 캡처와 설명, 주소 재발급 시 이전 주소 폐기 안내.
- 사용자가 실제 하이웍스 일정 연동 확인을 알림. 해당 직원의 Google 연결 완료와는 별개이며 이 릴리스에서 외부 권한이나 연결 주소를 변경하지 않음.
- 관련 검사 22개 통과, 도움말 템플릿 컴파일/렌더링 및 캡처 개인정보 제외 확인. DB migration 없음. 교육자료는 제작하지 않음.
- 배포 결과는 확인 후 기록.
