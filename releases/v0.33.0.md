# v0.33.0 · 전 직원 그룹 자동 관리

- 관리자가 실제 그룹·기존 구성원의 직원/Microsoft 연결을 검토하고 활성화한 일반 그룹만 자동 관리한다. 기존 그룹 ID·폴더 ACL은 그대로 두고 이름을 ‘전 직원’으로 정리한다. 새 그룹 생성 시 시스템 접두어를 붙이지 않는다.
- Workhub 재직 직원 등록 시 확인된 회사 Microsoft 계정을 추가하고, 사용 중지·직원 삭제·퇴사일 경과 시 제외한다. 퇴사일은 마지막 재직일로 취급하며 다음 날부터 제외한다. 퇴사 취소·재활성화는 재직 조건을 다시 만족하면 복원한다.
- 초기 기존 구성원 중 Workhub 미등록 직원은 최신 회사 디렉터리의 고유 직원 ID로 보존·추적한다. 신규 회사 디렉터리 계정만으로 문서 권한을 자동 부여하지 않는다. 계정 확인 실패·모호한 주소는 대기로 표시한다.
- 기존 표시 이름 연결은 초기 구성원 확인 화면에만 후보로 제시하고 관리자가 재확인한다. 이후 새 직원의 권한 부여는 정확한 회사 이메일을 검증하며 표시 이름·이메일 앞부분으로 추측하지 않는다.
- 1분 주기의 별도 백그라운드 작업과 사이트 단위 잠금, 매 변경 전 직원 상태·구성원 재확인, 승인한 관리자 연결 범위 검사, 결과 검증·감사 기록을 적용한다. 기본 소유자/전체 편집자/전체 열람자 그룹은 전환을 차단한다. 자동 그룹은 수동 구성원 변경을 막고 직원 정보에서 관리한다.
