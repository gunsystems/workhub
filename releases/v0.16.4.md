# v0.16.4 보고 검토 피드백 표시

- 저장된 검토 의견이 접힌 제출 이력 안에만 있어 작성자와 검토자 모두 찾기 어려웠습니다.
- 보고 상세 상단에 최신 검토 결과, 검토자, 작성 시각, 제출 버전과 피드백을 표시합니다.
- 보완 요청을 받은 작성자에게 보고 보완하기 버튼을 제공합니다.
- 재제출한 뒤 새 검토가 없으면 이전 제출본의 의견임을 명확히 표시합니다.
- 과거 검토 이력과 조회·검토 권한을 유지하며 새 데이터 마이그레이션은 없습니다.
