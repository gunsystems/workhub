# v0.31.0 · 증명서·서류 신청

## 이용 흐름
- 전자결재 안에 증명서·서류 탭을 별도로 추가한다. 재직·경력증명서, 원천징수영수증, 급여명세서, 기타 서류를 신청한다.
- 현재 기본값은 관리자 직접 접수다. 담당자를 지정하면 신규 신청부터 전달하며, 진행 중 신청의 일괄 또는 개별 재배정도 지원한다.
- 접수 대기 → 발급 준비 중 → 최종 PDF 등록 → 발급 완료. 회사 양식으로 만든 PDF를 담당자가 올리는 방식이며 직인·공식 증명서 자동 생성은 포함하지 않는다.
- 신청자는 신청내역 또는 처리 내역에서 PDF를 받는다. 접수 대기 중 취소, 사유 있는 반려·발급 취소, 변경 이력을 제공한다.
- 공통 결재함·조치 필요·메뉴 숫자·업무 알림과 연계한다. 확인된 회사 이메일에 일반 안내와 로그인 링크를 보내며 개인 서류를 이메일에 첨부하지 않는다.

## 개인정보와 운영
- 신청자·현재 담당자·시스템 관리자에게만 조회와 다운로드를 허용한다. 팀장·임원 직책으로 다른 직원의 개인 서류를 열 수 없다.
- PDF는 공개 URL이 없는 영구 디스크의 비공개 저장소에 보관하고, 다운로드마다 현재 계정·신청 상태·권한을 재검사한다. 발급 취소 후 추가 다운로드는 차단되지만 이미 받은 파일은 회수되지 않는다.
- 중복 제출 키, CSRF, 잠금·revision으로 중복 발급과 오래된 화면의 덮어쓰기를 방지한다.
- 전역 시스템 로그에는 처리·상태·버전 등만 기록한다. 신청 용도·본문·서류 내용은 전역 로그와 이메일에서 제외한다.
- 메일 발송 직전 현재 담당·열람권한·인증된 이메일·요청 버전을 다시 확인한다. 응답이 불확실한 전송은 자동 재발송하지 않는다.
- migration 0058은 신규 테이블만 추가한다. 이전 릴리스로 되돌릴 때 신규 테이블과 비공개 파일은 보존하며 역방향 migration으로 개인 기록을 삭제하지 않는다.

## 검증
- 신규 흐름·개인정보 격리·관리자 POST 발급·파일 다운로드·담당자 변경·stale 요청·메일 대상 재검사 9개 통과.
- 휴가·품의·도움말과의 관련 회귀 검사 84개 통과(이후 신규 검사 1개 추가).
- 전체 회귀·CI·운영 화면 확인 결과는 배포 후 기록한다. 실제 직원 서류 발급 및 실제 알림 발송 테스트는 수행하지 않는다.
- 직원 동석 공동문서 공동편집 검증은 기존 대기 항목으로 별도 유지한다.
