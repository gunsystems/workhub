# v0.23.3 · 자료명과 원래 파일명 분리

자료명은 화면의 표시 제목으로만 사용하고 다운로드 파일명은 보존된 원래 파일명을 사용합니다. 자료명과 원래 파일명이 다르면 첨부 목록에 파일명을 함께 표시합니다. 업로드 안내에도 두 이름의 용도를 명시합니다. 기존 파일 내용·저장 위치·권한·자료명은 변경하지 않습니다. 원래 파일명 기록이 없는 과거 자료는 기존 자료명을 사용하고, 이미지의 잘못된 확장자 보정은 유지합니다.

첨부·품의 집중 검사 52개, 전체 Django 685개 및 Node 9개 검사 통과. 실제 기존 첨부 목록에서 자료명과 원래 파일명의 분리 표시를 확인하고, 다운로드 시 원래 파일명이 사용되는 것을 확인했습니다. 기존 파일·자료명·결재 내용은 변경하지 않았습니다.
