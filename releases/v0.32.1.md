# v0.32.1 · 문서 수정·버전 이력

## 관리자 폴더 권한 현황

- 폴더 접근 관리의 ‘전체 폴더 권한 현황’에서 전체 문서함·하위 폴더를 순차 조회해 구조도로 표시한다. 폴더별 권한 원본·상속 여부·그룹과 현재 구성원·보호된 개인을 포함한 직접 권한을 조회한다.
- 서버 관리자 전용 GET/no-store이며 기존 위임 계정·선택 사이트 권한을 그대로 사용한다. 조회로 문서·권한을 변경하지 않는다. Limited Access를 내용 열람 권한으로 표시하지 않는다.
- 폴더·그룹·직원 검색, 모두 접기/펼치기, 최신 조회·중지, 폴더 접근 관리 링크를 제공한다. 그룹 구성원 요청은 현재 화면 조회 동안만 중복 제거한다. 서버/브라우저 영구 권한 캐시는 없다.
- 한 요청에서 하위 목록 한 페이지만 읽는다. 실패·중단·500개 위치/64단계 제한은 부분 조회로 명시한다. 중첩 그룹, 사이트 관리자, 개별 파일 별도 공유는 직원별 최종 접근 결과와 구분한다. 조회는 시점별로 진행하며 원자적 스냅샷은 아니다.

- 공동 문서의 파일별 수정 이력 버튼에서 Microsoft 저장 버전·마지막 수정자·시각·크기를 조회한다. 공동편집의 여러 변경이 한 저장 버전으로 묶일 수 있으며, 전체 동시 참여자 또는 문장·셀별 변경 추적을 뜻하지 않음을 명시한다.
- 직원 본인의 위임 토큰으로 현재 파일을 매번 다시 확인한다. 서버 앱 권한으로 우회하지 않으며 폴더·다른 문서함 요청은 거부한다.
- 1페이지씩 읽고 사용자·연결·문서에 묶인 암호화된 만료 커서로 이어 조회한다. 외부·반복 nextLink를 거부하고 다운로드 서명 주소와 토큰은 화면·로그·URL에 노출하지 않는다.
- 조회만 제공한다. 버전 복원·삭제·자동 다운로드·문서 변경 없음. 목록 로딩에는 이력 API를 호출하지 않으며 조회 결과는 저장하거나 다른 사용자와 공유하지 않는다.
