# v0.15.1 · 간단 업무 접근·완료, 이미지 자료, 댓글 알림

- 왼쪽 업무 관리에 간단 업무 메뉴를 추가하고 내 업무·전사/팀 현황에 별도 간단 업무 영역을 표시합니다. 기존 수행 점수와 기한 집계에 합산하지 않습니다.
- 단계 표시를 현재/완료 상태로 구분합니다. 담당자가 요청 확인을 마친 뒤 요청자는 전달된 의견·자료가 충분하면 결과 회신 전에도 ‘업무 완료 · 요청자 확인’으로 종료할 수 있습니다. 결과 회신 시각은 실제 회신이 없으면 생성하지 않습니다. 원래 결과 회신→최종 확인 경로도 유지합니다.
- 파일의 표시 이름과 원본 파일명을 분리하여 보존합니다. 다운로드 시 이미지의 파일 서명으로 확장자를 복원하므로, 기존 자료도 표시 이름에 확장자가 없다는 이유로 알 수 없는 파일이 되는 문제를 방지합니다. 원본 바이트는 변경하지 않습니다.
- 이미지 미리보기는 기존 업무 열람 권한을 재확인한 뒤 JPEG로 재생성하며 최대 640×480, 16MP 입력 제한을 적용합니다. HTML/SVG를 그대로 표시하지 않고 캐시를 금지합니다. 큰 이미지나 지원하지 않는 파일은 다운로드로 확인합니다.
- 일반 업무의 질문·의견과 기존 업무의 관리자 피드백에 Workhub 알림 및 선택된 이메일·하이웍스 채널을 연결합니다. 작성자는 제외하며 이메일은 이벤트/수신자 단위 중복 방지와 발송 전 계정·권한·이메일·채널 재확인을 적용합니다. 하이웍스 모바일 바로가기도 포함합니다.
- 기존 댓글을 일괄 재발송하거나 사용자의 실제 업무를 자동 완료하지 않습니다.

## 검증과 운영 기록
관련 자동 검사 81개 통과. 최종 전체 검사·배포와 실제 이미지 확인 결과는 운영 검증 후 기록합니다.

## 사용 확인
1. 내 업무의 간단 업무 영역 또는 왼쪽 간단 업무에서 요청을 엽니다.
2. 단계의 현재 표시를 확인하고, 담당자 확인 후 받은 자료가 충분하면 요청자가 업무 완료를 선택합니다.
3. 업무자료의 이미지 미리보기를 펼치거나 파일을 내려받아 확장자·내용을 확인합니다.
4. 알림 채널이 켜진 별도 확인용 업무에서 상대 계정으로 질문·의견을 남기고 이메일·하이웍스 앱의 알림을 확인합니다. 작성자 본인에게는 새 댓글 알림이 발송되지 않습니다.
