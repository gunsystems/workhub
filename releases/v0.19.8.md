# v0.19.8 · 후속 조치 취소 확인과 브라우저 심볼

- 내 배정 목록을 처리할 조치 / 취소 확인 / 처리 기록으로 구분.
- 취소된 퇴사 건은 처리 대기 대신 취소 확인 필요 표시. 담당자 본인만 취소 확인 가능.
- 취소 확인 시 별도 감사 이력 기록 후 처리 기록에서 조회. 업무 처리·증빙 승인과 구분하며 원래 상태/자료는 보존.
- 중복 클릭은 이력 중복 없이 처리. 활성 건이나 다른 담당자 항목은 취소 확인 불가.
- 취소 상세에서 취소 사유·일시 안내. 이미 변경한 외부 계정은 자동 복원하지 않음.
- 카드 최소폭/너비와 반응형 열 배치 보완.
- GUNSYSTEMS 녹색 G 심볼을 SVG 파비콘으로 공통 업무/로그인/비밀번호 재설정 화면에 적용.
- 캘린더와 도움말의 '일정 빠른 등록'을 '빠른 일정등록'으로 변경.
- 데이터 스키마 변경 없음. 실제 취소 확인은 사용자가 직접 수행하며 이번 검증에서 실제 퇴사 데이터를 변경하지 않음.
