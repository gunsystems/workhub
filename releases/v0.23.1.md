# v0.23.1 · 품의 금액·제출 안내

- 품의 목록·상세·품목 단가·행별 금액·합계에 천 단위 쉼표를 적용합니다. 입력 원본과 서버 계산 값은 변경하지 않습니다.
- 비용 품의의 증빙 미첨부 상태를 결재 제출 버튼 바로 위에 표시하고 증빙자료 추가 링크를 제공합니다. 증빙이 없는 경우 제출 버튼을 비활성화해 반복 클릭과 상태 혼동을 줄입니다. 기존 증빙 필수 조건은 유지합니다.
- 제출 전 결재순서 안내를 일반 직원에게 필요한 간단한 설명으로 정리합니다. 제출 후 실제 결재선은 유지합니다.
- 실제 사용자 품의를 대신 제출·승인하지 않습니다.

검사·배포·화면 확인 진행 중.
