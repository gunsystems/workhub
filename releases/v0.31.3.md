# v0.31.3 · 폴더를 선택해서 바로 권한 설정

- 권한 관리 진입 시 전사 공통 문서함을 기본 선택하고 첫 폴더 목록을 자동으로 펼친다. 폴더를 누르면 구성원 탭에서도 폴더 권한 탭으로 이동한다.
- 선택 대상이 문서함 전체인지 폴더인지 표시하고 폴더 이름을 권한 화면 제목에 명시한다. 그룹별 연결 없음·보기·편집을 선택하고 고정된 권한 저장 버튼에서 검토한다.
- 상위 권한을 사용하는 대상도 바로 선택 가능하다. 검토 화면에서 선택 대상부터 별도로 적용함을 명시하고, 확인 후 기존 권한 복사와 선택한 그룹 변경을 함께 처리한다.
- 모든 대상·역할을 외부 쓰기 전에 검증한다. 기존 관리자·개인·변경하지 않은 그룹 권한 및 하위의 별도 권한을 보존한다. 상태 충돌·복사 검증 실패 시 중단하며 일부 처리 가능성은 감사 로그에 기록한다.
- 폴더 이동 중 이전 권한 화면의 입력을 잠그고, 실패 시 복구한다. 미저장 변경 경고 및 세션 만료·트리 페이지 처리 유지. DB migration 없음.
