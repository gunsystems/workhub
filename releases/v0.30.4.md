# v0.30.4 · 문서 읽기 HTTP 연결 재사용

- v0.30.3 일괄 읽기만으로는 실제 탐색 개선이 확인되지 않았습니다. 같은 계정·교육 자료 폴더 반복 5회 자동화 확인 중앙값: v0.30.2 2161ms, v0.30.3 2208ms. 도구 왕복이 포함되고 배포 사이 시간·네트워크 차이가 있어 인과적 성능 향상을 주장하지 않습니다.
- 관측된 v0.30.3 서버 시간은 문서함/연결 확인 약 0.65~0.81초, 폴더/목록 batch 약 0.68~1.22초, 렌더링 약 0.035~0.071초였습니다.
- Graph 읽기에 스레드별 TLS/TCP 연결 풀을 재사용합니다. 캐시하는 것은 연결뿐이며 사용자 토큰은 각 요청에 명시합니다. Session.prepare_request를 사용하지 않아 세션의 이전 인증·쿠키·헤더를 적용하지 않고 쿠키 저장/송신도 차단합니다.
- 인증서 검증, 프록시 환경, 읽기 응답 1MB 제한, timeout, 리다이렉트 차단, 자동 재시도 없음 유지. 쓰기·계정 토큰 발급 전송 방식은 변경하지 않습니다.
- 관련 검사 67개 및 전체 GitHub 회귀 검사 통과. 운영 배포 dep-dbtau3lg1s2s7399ua50 live, 인증된 화면의 v0.30.4 확인.
- 같은 빈 폴더(전사 공통 / 교육 자료), 같은 계정·IAB, 클릭 시작부터 완료 표시 확인까지 동일 자동화로 각 버전 반복 5회 측정. 기존 v0.30.2: [2161,1877,2661,2906,1433]ms, 중앙값 2161ms. v0.30.4: [1232,755,760,752,886]ms, 중앙값 760ms. 이번 표본에서 중앙값 약 64.83% 감소.
- v0.30.4 폴더 조회 서버 전체 시간 [840.3,462.3,486.0,486.5,527.3]ms, 중앙값 486.5ms. 문서함 확인은 약 0.20~0.23초, 폴더/목록은 약 0.22~0.58초.
- 최초 폴더 이동은 v0.30.2 3173ms, v0.30.3 2371ms, v0.30.4 2044ms로 반복 중앙값에서 제외. 이는 순수한 cold 인증 측정이 아닙니다.
- 한 사용자·빈 폴더·소표본이며 배포/재로그인 전후 네트워크 차이와 자동화 도구 오버헤드가 포함됩니다. 대량 파일·동시 접속·다른 네트워크의 성능 보장은 아닙니다. 실제 직원 권한 변경 없이 읽기 이동만 수행했고, 거부·계정 분리·사이트 경계는 자동 검사로 검증했습니다.
