# v0.30.4 · 문서 읽기 HTTP 연결 재사용

- v0.30.3 일괄 읽기만으로는 실제 탐색 개선이 확인되지 않았습니다. 같은 계정·교육 자료 폴더 반복 5회 자동화 확인 중앙값: v0.30.2 2161ms, v0.30.3 2208ms. 도구 왕복이 포함되고 배포 사이 시간·네트워크 차이가 있어 인과적 성능 향상을 주장하지 않습니다.
- 관측된 v0.30.3 서버 시간은 문서함/연결 확인 약 0.65~0.81초, 폴더/목록 batch 약 0.68~1.22초, 렌더링 약 0.035~0.071초였습니다.
- Graph 읽기에 스레드별 TLS/TCP 연결 풀을 재사용합니다. 캐시하는 것은 연결뿐이며 사용자 토큰은 각 요청에 명시합니다. Session.prepare_request를 사용하지 않아 세션의 이전 인증·쿠키·헤더를 적용하지 않고 쿠키 저장/송신도 차단합니다.
- 인증서 검증, 프록시 환경, 읽기 응답 1MB 제한, timeout, 리다이렉트 차단, 자동 재시도 없음 유지. 쓰기·계정 토큰 발급 전송 방식은 변경하지 않습니다.
- 관련 검사 67개 통과. 최종 CI와 운영 전후 비교는 이후 확인해 기록합니다.
