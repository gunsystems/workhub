# Workhub v0.14.1 — 작성 미리보기·설문 관리자 전용화·안내 정리

- 설문조사 메뉴/목록은 관리자만 접근. 직원은 안내 메일의 개별 응답 링크로 로그인 후 참여. 임원 직책만으로 설문 관리 권한을 부여하지 않음. 신규 작성 설문은 이메일 안내를 기본 필수로 적용하고 하이웍스 알림은 선택. 기존 확인용 설문은 외부 발송 없이 유지.
- 공지·설문 작성 중 브라우저에서만 생성하는 미리보기 모달. 저장·게시·발송 요청 없음. 제목·본문/질문·선택지·대상·기간·채널 표시. 모든 입력을 textContent로 렌더링하여 HTML 실행 방지. 모바일 스크롤·닫기/ESC 지원.
- 대시보드 점수/관리 필요 설명을 제목·산식·목록·조회 범위로 분리하고 줄바꿈·여백 정리. 기존 점수 산식/권한은 변경하지 않음.
- 가비아 회신과 사용자의 모바일 캡처로 알림 수신 확인. h 로고 하이웍스 앱의 종 모양 알림에서 확인하며 별도 메신저 앱이 아님을 도움말에 반영.
- v0.14.0 운영 확인: 본인 1명 대상, 외부 채널을 끈 확인용 설문 1을 작성·배포. 이상건 계정으로 임시 저장 및 제출 완료 확인. 대표 계정의 임원 평가 입력과 날짜 높이 48px, 360/390/430px 가로 넘침 없음. 시스템 관리자 평가 URL 403 확인. 실제 직원 평가 점수는 생성하지 않음.
- DB migration 없음. 검증·운영 결과 후속 기록 예정.
