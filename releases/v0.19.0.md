# v0.19.0 내 정보 사원카드와 캘린더 빠른 등록

- 계정 메뉴에 내 정보·사원카드를 추가합니다. 별도 왼쪽 메뉴를 늘리지 않습니다.
- 직원 기본 정보에 직급·생년월일·연락처를 추가합니다. 사번·입사일과 함께 관리자 설정에서 관리합니다. 기존 로그인 계정·업무 권한은 변경하지 않습니다.
- 내 정보는 본인만, 다른 직원의 정보·카드 미리보기는 관리자만 조회할 수 있습니다. 개인정보 응답은 캐시하지 않습니다.
- 디지털 사원카드는 이름·부서·직급·사번을 담아 PNG로 저장합니다. 생년월일·연락처는 카드 이미지나 이미지 생성 데이터에 포함하지 않습니다. 감사 로그에도 두 항목의 원문을 기록하지 않고 변경 항목만 남깁니다.
- 캘린더 날짜 빈 영역·＋ 버튼에서 빠른 등록 창을 엽니다. 일정명·날짜·담당자를 먼저 받고, 종일 또는 시간·업무 종류·장소·설명·배정 알림을 설정할 수 있습니다.
- 빠른 저장은 기존 일반 업무 등록 로직을 재사용해 수행자·알림·업무 이력을 유지합니다. 사용자별 서명 토큰과 DB 키로 중복 저장을 방지합니다.
- 상세 입력은 기존 전체 등록 화면으로 이어지며 입력한 값이 유지됩니다. 보고·결재·첨부는 전체 화면에서 추가합니다. 기존 일정 클릭은 상세 조회로 유지합니다.
- 휴가 신청의 직원 공개 상태와 연차 일수는 변경하지 않습니다. 디지털 카드로 출입 시스템을 제어하지 않습니다.

## 확인 방법

직원: 왼쪽 아래 계정 메뉴 → 내 정보·사원카드. 관리자: 직원 관리 → 직원·연차 설정 → 등록된 직원 정보의 정보·사원카드.

캘린더: 빈 날짜 영역 또는 ＋ → 제목·담당자 확인 → 저장. 상세 입력을 선택하면 보고·결재·첨부 설정을 이어서 할 수 있습니다.

## 데이터와 배포

0047_employee_profile_calendar_quick는 기존 직원 기본 정보에 선택 필드 3개와 중복 등록 방지 테이블을 추가합니다. 실제 직원 개인정보는 소스·정적 예시·릴리스 기록에 넣지 않습니다. 직원이 아직 Workhub에 등록되지 않았다면 직원 기록·초대·계정을 자동 생성하지 않습니다.

## 검증

프로필 권한·개인정보 로그 마스킹·카드 데이터·빠른 일정 저장·중복 방지·시간·상세 화면 이동 등을 포함한 관련 검사 45개 통과. 전체 CI와 실제 PC·모바일 결과는 배포 후 기록합니다.
