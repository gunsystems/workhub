# v0.35.0 — 표준 프로젝트 문서 생성·종료·보관

- 관리자가 기존 Workhub 프로젝트에 표준 문서 폴더를 연결. 연도·고객/내부 과제·활성 벤더·유형·참여자 입력, 폴더명 미리보기 및 실행 전 검토.
- 새 프로젝트 그룹과 표준 하위 폴더 4개 생성. 참여자 편집, 경영진 보기, 관리자 관리. 개인 직접 ACL 없음.
- 총괄 담당자는 종료·보관 요청, 관리자는 적용 범위를 확인 후 실행. 종료가 업무 항목의 완료 상태를 자동 변경하지 않음.
- 직접 생성한 프로젝트만 완료프로젝트/종료연도로 이관. 기존 폴더를 자동 연결하거나 이관하지 않음.
- SharePoint CreateCopyJobs 실제 이동 사용. 전체 버전 보존, 충돌 시 실패, 잠금·스키마·보관 버전 수 제한을 우회하지 않음. 작업 정보는 암호화 저장하며 HTML·로그에 노출하지 않음.
- 이관 전 참여자 편집을 중지하고 자료 목록 및 버전을 검증. 이관 후 영업·기술 하위 ★와 프로젝트 루트 ★에 직무별 읽기 권한 적용.
- 모든 검증 후 SharedDocument 식별자를 갱신해 기존 업무 연결 FK 유지, 프로젝트 문서 상태 종료로 전환. 중복 식별자는 자동 합치지 않음.
- 신규 실행 기록·요청 및 단계별 작업은 시스템 로그 기록. 외부 작업 결과가 불명확하면 자동 재실행하지 않음.
- 자동 이관은 프로젝트 항목 200개, 파일별 버전 500개 이내. 별도 하위 고유 권한이나 기존 동명 경로는 자동 처리하지 않고 관리자 검토 필요.
- migration 0064: 프로젝트 문서 상태와 신규 DocumentProject 기록. 기존 자료 이동·수정·삭제 없음.

확인: 관련 Django 175개 검사, 순차 실행·오류 후 중복 요청 방지 브라우저 검사. 운영 실제 이관 검증 결과는 별도 적용 기록에 남김.
