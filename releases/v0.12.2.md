# Workhub v0.12.2 — 명확한 드래그 앤 드롭 첨부와 등록 지연 판정 수정

## 파일 첨부

- 업무 등록·업무 요청·협조 요청·보고서·업무자료에서 전용 점선 영역으로 파일을 끌어다 놓거나 파일 선택 버튼을 사용합니다.
- 파일 선택은 업로드가 아닙니다. 파일명·크기와 ‘아직 업로드되지 않았습니다’를 표시합니다.
- 등록·저장 시 ‘업로드 중’을 표시하고, 성공한 이동 화면에 ‘업로드 완료’를 표시합니다.
- 선택 취소, 잘못된 형식·빈 파일·용량 초과·다중 파일·폴더 안내를 제공합니다.
- 첨부 영역 밖으로 떨어뜨린 파일이 작성 중인 화면을 파일 미리보기로 바꾸지 않도록 방지합니다.
- 파일당 20MB, 보고서 첨부는 10MB. 한 번에 한 파일이며 추가 자료는 반복 등록할 수 있습니다.
- 파일명은 텍스트로 처리하고, 기존 서버 검증·업무별 접근 권한은 유지합니다.

## 지연 등록 표시

기존에는 화면을 열 때 자동으로 채운 시작 시간보다 5분 늦게 저장하면 당일 업무도 지연 등록으로 표시했습니다.
일반 업무의 당일 작성 소요시간은 지연으로 보지 않도록 수정합니다.

- 일반 업무: 최초 시작일이 등록일보다 이전 날짜인 경우 소급 등록으로 판정합니다.
- 실제 수행 시작 시간이 지정된 일정: 그 시간이 등록 시각보다 5분 넘게 지난 경우 기존 판정을 유지합니다.
- 기존 표시: 최초 계획상 당일 업무이며 실제 수행 시간이 따로 없던 지연 표시만 해제합니다.
- 최초 등록 시각·시작일·마감일·일정 변경 이력은 그대로 보존하고 정정 사유는 시스템 로그에 남깁니다.

마이그레이션 0031은 해당 표시가 있을 때 운영 DB 백업과 무결성 확인 후 late 플래그만 정정합니다.

## 확인 방법

1. 업무자료의 자료 추가에서 파일을 끌어 놓습니다. 파일명·크기와 ‘아직 업로드되지 않았습니다’를 확인합니다.
2. 선택 취소 후 파일 선택 버튼으로도 같은 상태가 되는지 확인합니다.
3. 자료 등록을 누르면 업로드 중 안내 뒤 자료 목록과 업로드 완료 안내가 표시됩니다.
4. 파일명 클릭으로 내려받습니다. 초과 용량·지원하지 않는 형식·여러 파일은 등록 전 안내합니다.
5. 오늘 시작하는 일반 업무는 작성에 5분 이상 걸려도 지연 등록으로 표시되지 않습니다.

전용 UI의 드롭·검증·선택 취소·업로드 상태와 외부 드롭 방지 검사는 Node 테스트로 검증합니다.
