# v0.30.2 · 공동 문서 중복 탐색 요청 방지

- 같은 폴더·다음 페이지를 로딩 중 반복 클릭하면 기존 진행 중 요청을 유지합니다. 기존에는 매번 취소 후 재요청해 서버의 Microsoft 조회가 중복될 수 있었습니다.
- 완료·실패 후에는 다시 요청합니다. 문서 목록·권한 결과 캐시는 추가하지 않았으며 사용자별 위임 인증, 서버 권한 확인, no-store를 유지합니다.
- 다른 폴더로 이동하면 이전 요청을 취소하고 늦은 응답을 무시하는 기존 동작을 유지합니다.
- 검증: 탐색 JavaScript 회귀 검사(반복 클릭 3회→HTTP 요청 1회, 완료 후 재조회, 실패 후 재시도, 이전 응답 경합, 접근 거부·로그인 이동), Django 문서 연결·탐색·권한 경계 검사 44개 통과.
- 범위: 연속 클릭으로 생기는 중복 요청 감소입니다. 한 번 클릭한 폴더의 Microsoft 응답 시간 자체를 단축하거나 운영 응답 시간을 실측한 결과는 아닙니다.
