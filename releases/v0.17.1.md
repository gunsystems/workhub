# v0.17.1 직원별 주간보고 검토 중심으로 정리

- 팀원→팀장 주간보고 작성·제출·확인 완료·보완 요청은 유지합니다.
- 팀장 자동 취합과 임원 보고는 후속 검토로 보류합니다. 취합 버튼과 작성 패널을 숨기고, 직접 주소 및 예전 화면의 취합 요청도 차단합니다.
- 업무 보고에 직원별 주간보고 펼침 카드를 추가합니다. 이번 주 진행 업무·차주 예정 업무·이슈를 구분하고 최근 검토 피드백을 함께 표시합니다.
- 제출 당시 내용을 표시하며 재제출 전 수정 중인 내용은 노출하지 않습니다. 기존 열람 권한과 보고 상세의 검토 권한은 유지합니다.
- 본문에 ‘↳ 출처: … 제출 v1’을 생성하지 않습니다. 기존 원본 제출본 연결 및 이력은 삭제하지 않습니다.
- 업무 등록의 자동 그룹핑 안내와 보고 분류 선택을 숨기고 고객사·벤더사 정보 입력은 유지합니다.
- 기존 그룹핑 예시 주소는 가상 직원별 검토 예시로 교체합니다. 실제 자료와 연결되지 않으며 저장·제출할 수 없습니다.
- DB 마이그레이션과 기존 업무·보고의 일괄 변경은 없습니다. 휴가 관리자 미리보기 범위는 유지합니다.

## 확인 방법
1. 업무 보고에서 조회 주간을 선택합니다.
2. 주간보고 제출 현황으로 제출 여부를 확인합니다.
3. 직원별 주간보고에서 이름을 눌러 내용을 펼칩니다.
4. 보고 상세 · 검토하기에서 확인 완료 또는 보완 요청을 남깁니다.

## 후속 보류
- 팀장 고객사·벤더사별 자동 취합 및 본부장·대표 재취합 보고.
- 정해진 제출 기한에 따른 자동 독려와 점수화는 별도 후속 범위입니다.
