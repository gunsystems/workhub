# Workhub v0.11.0 업무 요청 · 팀 간 협조 요청
2026-11-10 · Asia/Seoul

## 변경
- 업무 등록에 내 업무/업무 요청/업무협조 요청 진입 경로 추가.
- 업무 요청은 기존 공동 수행·보고·결재·배정 메일/메신저에 연결하고 접수함의 보낸 요청에서 확인.
- 협조 요청에 지원 팀·프로젝트·고객사·솔루션·희망 기간·회신 기한·필요 인원·희망 담당자·자료 링크.
- 접수·협의·보완·지원 불가·취소, 요청자 보완 시 변경 전 정보 보존, 관리자 조치 필요.
- 수신 팀장·부서 관리자·임원 배정. 대행자는 접수·협의만 허용. 배정 전 비관련 직원·비공개 프로젝트 조회 차단.
- 희망 기간 중복 팀 업무 경고, 인원/기간 조정 사유, 확정 인원별 투입 기간·역할 및 변경 이력.
- 기존 수행 업무 1건에 연결해 중복 배정 방지, 요청자 참조 연결, 완료 후 요청자 결과 확인·별도 추가 지원 요청.
- 요청 관련 내부 알림 및 도움말 흐름도. 기존 사이드바 메뉴 유지.
- 신규 양식 제출 키, 변경 revision, SQLite 잠금 재시도 및 안내. 인증·계정·Google/하이웍스 비밀 설정 변경 없음.

## 검증 및 배포
검증·운영 배포 결과 기록 예정. migration 0029는 추가형 필드·테이블이며 기존 요청/업무는 유지합니다.

## 범위
배정 전에는 내부 알림만 사용합니다. 개인 투입 기간은 계획 기록이며 캘린더는 수행 업무 공통 기간을 사용합니다. 자동 인력 배정·근태/휴가 판단·파일 저장소 통합은 포함하지 않습니다.
