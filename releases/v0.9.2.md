# Workhub v0.9.2 공통 화면 정렬·간격 정리

2026-11-09 · Asia/Seoul

- 보고 목록의 조회 라벨을 입력칸 위로 통일하고 입력/선택/조회 버튼의 높이를 44px 및 하단 기준선으로 맞춤.
- 공통 detail 박스의 400px 강제 최소 높이 제거. 연속된 박스 간격 24px, 목록/본문 폭과 제목·본문 간격 정리.
- 업무 현황·직원 검색에 표시 라벨 추가. 업무·보고·직원·캘린더·전사 현황·시스템 로그의 조회 조건을 공통 스타일로 정리.
- 시스템 로그의 제목/조회 버튼/초기화 버튼, 보고 검토 입력폼, 캘린더 업무 연결/직원 계정 관리의 가운데 정렬을 보완.
- 개인 보드의 카드 내부 디자인과 캘린더 격자 규칙은 유지하며, 기존 개별 화면의 detail 간격 예외를 정리.
- 좁은 화면에서 조회 조건과 업무 등록 그리드는 한 열로 줄바꿈. 가로 표는 컨테이너 안에서 스크롤.
- 55개 HTML 템플릿 컴파일 성공, 관련 기존 검사 39개 통과. 새 정적 파일의 로컬 manifest를 collectstatic으로 갱신한 후 검사함.
- 새 테스트 탭에서 보고 목록 로컬 미리보기의 조회 정렬/빈 목록/하단 박스 간격을 시각 확인. 기존 사용자 탭/실제 업무 데이터는 수정하지 않음.
- UI 변경이며 DB migration 없음. 실제 직원별 모든 데이터 조합과 모든 기기 화면을 검증했다는 뜻은 아님.
- 배포 결과는 확인 후 기록.
