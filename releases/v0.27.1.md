# v0.27.1 · 역할에 맞는 도움말 정리

- 공동 문서의 일반 사용 안내와 문서 관리 담당자 안내를 분리합니다. SharePoint 권한 변경 설명은 시스템 관리자에게만, 폴더 관리 설명은 관리자·대표에게만 표시합니다.
- 직원 공지 확인·설문 응답·배정된 후속 조치·내 정보·업무보고·일정 관리 도움말을 실제 사용 절차 중심으로 정리합니다.
- 전자결재의 대표 본인 결재 설명, 개발·테스트와 기능 보류 문구를 공통 도움말에서 제거합니다.
- 전체 사용 가이드의 관리자 초대·연동 안내를 관리자에게만 표시하고 오래된 알림 설명을 정리합니다.
- 역할별 안내는 서버에서 구성하며 기능 접근 권한과 문서 권한을 변경하지 않습니다. 데이터 변경·마이그레이션은 없습니다.

## 검증

- 일반 직원·팀장·대표·관리자의 도움말 및 흐름도, 실제 템플릿 출력, 요청 간 안내 혼입 방지 검사.
- 전체 검사·배포 확인은 배포 기록에 추가합니다.
