# v0.19.3 내 정보 주소 검색

- 우편번호 옆 주소 검색 버튼으로 카카오 우편번호 서비스를 페이지 안에 표시합니다. 공식 SDK는 버튼을 누를 때만 불러옵니다.
- 도로명·지번 결과와 참고 건물명을 기본 주소에 반영하고 상세 주소로 포커스를 이동합니다. 다른 주소를 선택하면 이전 상세 주소를 비워 잘못된 동·호수 사용을 방지합니다. 같은 주소를 다시 고르면 상세 주소는 유지합니다.
- 결과 선택은 입력만 변경하며 주소 저장 버튼을 눌러야 저장합니다. 기존 주소나 상세 주소를 자동 검색어로 전송하지 않습니다.
- 검색 닫기, 로딩 취소, 오류 재시도와 수동 입력을 지원합니다. 공식 로고를 숨기거나 SDK를 수정하지 않습니다.
- 모바일에서는 새 창이나 고정 레이어 대신 페이지 내 검색을 사용하고 높이를 결과에 맞춰 조절합니다. 인증·주소 권한·저장 검증·마이그레이션은 변경하지 않습니다.

참고: https://postcode.map.kakao.com/guide
SDK: https://t1.kakaocdn.net/mapjsapi/bundle/postcode/prod/postcode.v2.js
