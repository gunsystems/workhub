# 주간업무보고 보강 — 개발 브랜치, 운영 미반영

## 요구사항과 구현
- 주간을 고르면 해당 주 월~일의 본인 담당/참여 업무를 이번 주 진행 업무에, 다음 주 월~일 업무를 차주 예정 업무에 초안으로 넣는다.
- 월~금 사용을 기본으로 하되 토·일 업무가 있으면 함께 취합한다. 여러 날에 걸친 업무는 겹치는 기간을 표시해 주당 한 번 정리한다.
- 한국 시간, 종료 시각 exclusive 자정 처리. 취소·초안·다른 직원 단독 업무 및 개인 보드·Google/Hiworks 외부 일정 제외.
- 직원은 두 영역과 선택 항목인 공유·지원 필요사항을 수정해 임시 저장/제출한다. 금요일 제한이나 자동 발송 없음.
- 캘린더 변경으로 이미 작성한 보고를 덮어쓰지 않는다. 초안은 실제 성과로 자동 판정하지 않는다.
- 보고받을 사람 기본값: 팀원은 같은 팀의 팀장, 팀장은 본부장/대표. 여러 후보 또는 공석이면 임의 선정하지 않고 직접 확인한다.
- 제출본에 이번 주/차주/지원 요청을 버전으로 보존한다. 제출 후 보완 요청→수정→재제출의 기존 흐름 유지.
- 팀장/부서관리자: 해당 팀의 주차별 미제출/제출/보완 요청/확인 완료 조회. 임원/관리자: 전사 범위. 일일보고·다른 주 보고·작성 중 초안은 해당 주 제출로 계산하지 않음.
- 작성 중 본문은 작성자만, 제출 후에는 작성자/보고받는 사람/권한 있는 관리자·팀장/임원만 접근. 같은 팀 일반 동료의 보고 열람 범위를 축소한다.

## 데이터와 성능
0038은 기존 보고에 기본값이 빈 추가 필드만 도입한다. 기존 제출 JSON은 변경하지 않는다. 취합 쿼리는 본인 수행 업무와 2주 범위를 먼저 필터링한다. 전체 프로그램에 크기 문제를 확인한 것은 아니다. 기존 전체 캘린더의 장기 누적 데이터 조회는 후속 성능 점검 후보.
