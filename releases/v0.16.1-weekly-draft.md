# v0.16.1 — 캘린더 기반 주간업무보고

## 동작
업무 보고 → 조회 주간 선택 → 캘린더로 주간보고 작성. 이번 주 진행 업무/차주 예정 업무를 본인의 Workhub 캘린더에서 초안으로 취합한다. 직원이 실제 수행 결과와 변경된 계획을 수정해 작성 중 저장 또는 제출한다. 금요일 외에도 가능하다.

- 월요일~일요일, 한국 시간. 주말 업무 포함. 여러 날 업무는 해당 주와 겹치는 기간을 표시해 주당 한 번 정리.
- 본인 담당·참여 업무만 취합. 취소/초안/개인 보드/외부 Google·하이웍스 원본 일정 제외.
- 공유·지원 필요사항은 선택 입력. 캘린더 계획을 완료 실적으로 자동 판정하지 않음.
- 저장한 내용은 이후 캘린더 변경으로 덮어쓰지 않음. 제출본은 이번 주/차주/지원 요청을 버전으로 보존. 보완 요청 후 수정·재제출.
- 팀장/부서관리자는 자기 팀, 임원/관리자는 전사 범위의 주차별 미제출/제출 완료/보완 요청/확인 완료 확인. 일일보고·다른 주 보고·작성 중 초안은 해당 주 제출로 계산하지 않음.
- 작성 중 본문은 작성자만 조회. 제출본은 작성자/보고받는 사람/권한 있는 관리자·팀장·임원에게 제공. 같은 팀 일반 동료의 보고 열람 범위를 축소.
- 팀장 지정 시 기본 보고 대상 제안. 후보가 없거나 여러 명이면 임의 선정하지 않으므로 보고받을 사람을 확인해 선택해야 함.
