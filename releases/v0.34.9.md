# v0.34.9 — 벤더 관리와 문서함 표시 정리

- 관리자 공동 문서 화면에 벤더 관리 진입점을 추가.
- 벤더 추가는 여섯 지정 위치의 폴더 생성 범위를 검토한 뒤 순차 적용. 기존 경로 충돌 시 덮어쓰지 않고 중단.
- 벤더 비활성화·재활성화는 선택 목록만 변경하며 기존 폴더·파일·권한을 유지.
- 새 벤더는 여섯 폴더의 생성 완료 확인 후에만 활성 목록에 포함.
- 등록명 중복·금지 문자, 관리자 연결 범위, 실행 중 중복 작업과 결과 불명확 시 재실행을 차단.
- 전사공통 문서함은 ‘표준 자료’, 기존 전사 공통은 ‘기존 자료’로 구분 표시. SharePoint 이름과 파일은 변경하지 않음.
- 신규 목록 저장용 migration 0063. 프로젝트 생성 화면 연동은 후속 프로젝트 기능에서 적용.
