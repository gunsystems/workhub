# v0.35.3 — 이관 버전 검증 정규화

- 이관된 파일의 경로·종류·용량, 기존 모든 버전 번호·용량·수정자 표시·저장 시각, 공통 제공 파일 지문을 비교.
- 문서함 간 이동에서 달라질 수 있는 제공자 내부 사용자 식별자, 빈 지문 속성, 같은 시각의 문자열 표기 차이를 자료 손실로 오판하지 않도록 정규화.
- 기존 버전 누락·파일 용량 변경·지문 불일치는 계속 차단. 버전의 서버 내부 식별자는 권한 판정에 사용하지 않음.
- 이미 이동한 자료의 재검증은 조회만 수행. 새로운 이관 요청이나 파일 수정 없음.
- 정상 메타데이터 표기 차이와 실제 자료 손실을 구분하는 회귀 검사 추가.
