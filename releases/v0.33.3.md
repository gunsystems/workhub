# v0.33.3 · 폴더·파일 접근 그룹 추가 오류 수정

- 그룹 추가 시 숨겨진 action 입력이 HTMLFormElement.action 속성을 가려 URL 생성이 실패하던 오류를 수정한다. 명시적인 action 속성값과 현재 페이지 기준 URL을 사용한다.
- 전 직원 등 그룹을 저장 전 목록에 추가하고 기본 보기 권한·구성원 표시·중복 추가 방지를 정상 처리한다. 추가 자체는 권한 저장이 아니며 최종 검토·적용 절차를 유지한다.
- 동일한 action 이름 충돌과 상대 주소를 재현하는 회귀 검사에서 수정 전 실패·수정 후 통과를 확인한다.
