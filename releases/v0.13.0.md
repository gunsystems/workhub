# Workhub v0.13.0 — 명시적 배정 확인

업무 처리 흐름에서 배정 확인 전 진행 보고·수행 완료·완료 보고를 서버에서도 차단합니다. 배정 확인 시 수행자 진행률을 최소 1%로 표시하고, 확인 버튼은 완료 표시로 바뀝니다. 공동 수행자는 각자 확인해야 합니다. 확인 대기 및 수행자별 배정 이후 경과 시간을 담당자와 지시자가 조회 가능한 업무 목록·상세에서 확인합니다. 시간은 새로고침 시 갱신하며 임의의 지연 기준으로 자동 판정하지 않습니다. 마감일과 기존 감사 기록은 유지합니다. 중복 확인은 기록하지 않으며 배정 확인만으로 진행 보고 시각을 갱신하지 않습니다. 수행자별 배정 시각 필드 추가. 기존 행은 업무의 최근 배정일을 기준으로 복원합니다. 운영 SQLite는 마이그레이션 전에 백업·무결성 검사를 수행합니다.

단계별 업무 처리 안내와 역할별 다음 동작을 표시합니다. 완료 버튼은 업무 수행 완료·완료 보고 제출·업무 완료로 구분하고 일정이라는 표현을 제거합니다.

기존 방식 업무도 명시적 배정 확인 후 진행·완료 보고하도록 동일하게 차단합니다.
