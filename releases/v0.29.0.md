# v0.29.0 · 관리자 문서 권한 관리

## 동작
- 공동 문서 폴더·파일의 ⋯ 메뉴에서 직원별 보기·편집·허용하지 않음을 선택하고 변경 사유를 남깁니다.
- 적용 전 허용 대상과 기존 일반 개인·그룹 권한 해제 범위를 확인합니다.
- 실제 SharePoint 권한을 조회·변경합니다. Workhub와 별도 권한표를 운영하지 않습니다.
- 소유자·권한 관리자·현재 처리 계정은 보존합니다. 상속하는 하위 자료에는 적용되고 이미 독립 권한인 하위 자료는 유지됩니다.
- 일반 직원은 자신의 Microsoft 권한으로만 문서를 조회합니다. 관리자 연결을 빌려 쓰거나 서버 앱 토큰으로 대체하지 않습니다.
- 권한 변경 시작·처리 단계·결과·부분 실패를 시스템 로그에 기록합니다.

## 설정 및 검증 상태
- 문서 앱의 SharePoint 위임 Sites.Selected 관리자 동의, 관리자용 콜백, 전용 문서 사이트 fullcontrol 설정을 완료했습니다.
- 사용자가 2026-11-15 전용 사이트 권한 관리 확대 및 설정용 임시 권한 회수를 승인했습니다.
- 일반 Edge의 공식 Graph Explorer에서 전용 사이트의 기존 앱 grant를 fullcontrol로 변경했고 GET 재조회로 확인했습니다. 설정용 Graph Explorer 사용자 동의는 회수했으며 My Apps에서 권한 없음 상태를 확인했습니다.
- 전체 Django 827개, Node 검사 10개 통과(CI 43713042233, job 132808584016). 로컬 관련 Django 85개도 통과했습니다. 실제 연결 검증은 미완료입니다.
- PR #23 병합(13a02fdb492fecc1b4ed9da18b1dc331224d8dd6), Render 배포 dep-dbsrm261egvs73ema5ng Live 확인. GUNSYSTEMS 관리자에서 lee 회사 계정 연결, 실제 문서함 목록과 검증 파일의 SharePoint 권한 조회에 성공했습니다.
- 실제 화면에서 직접 항목 권한이 없는 사이트 관리자가 ‘허용하지 않음’으로 표시되는 문제를 발견했습니다. 연결 관리자 이메일은 ‘관리자 접근 유지’로 고정하는 보완 커밋 7326b2e를 준비했고 관련 검사 20개가 통과했습니다. 모바일 390px에서 입력칸이 화면을 넘지 않는 것을 확인했습니다.
- 사용자 승인 후 내용 없는 검증 파일에서 김예린 보기 권한 허용→실제 ACL 재조회→해제→실제 ACL 재조회를 완료했습니다. SharePoint 원본의 액세스 관리에서도 김예린 권한이 없고 소유자 계정·소유자 그룹만 남는 것을 확인했습니다. 다른 문서·폴더는 변경하지 않았습니다.
- 시스템 로그에서 권한 변경 시작·각 단계·변경 전후 기록과 gunsystems 처리자를 확인했습니다. 직원 본인 로그인으로 해당 파일 열기/거부, SharePoint에서 직접 변경한 뒤 Workhub에 재조회하는 별도 검증은 하지 않았습니다.
- 보완 커밋의 전체 CI 43722943918은 성공했습니다. Render 보완 배포 dep-dbsrt1d6e07s73an7o90 Live 확인 후 실제 화면에서 이상건은 비활성 ‘관리자 접근 유지’, 김예린은 ‘허용하지 않음’인 것을 확인했습니다.
- 직접 SharePoint/Office에서 수행한 변경을 Workhub 로그가 자동 수집하지는 않습니다. Microsoft 감사 로그에서 별도로 확인합니다.

## 변경 방식
- 관리자 전용 별도 OAuth 연결, PKCE·state·사용자/테넌트/사이트 대조, 암호화 refresh token.
- 일회용·10분 만료 미리보기, 서버측 직원 정보 재검증, CSRF와 대상별 변경 잠금.
- 매 단계 현재 ACL 재조회 및 변경 감지 시 중단. 여러 Microsoft API 호출은 원자적 트랜잭션이 아니므로 부분 실패 시 실제 권한을 재조회해야 합니다.
- migration 0056: 별도 관리자 연결/권한 변경 잠금 테이블 추가. 기존 직원·업무·문서 데이터 변경 없음.
- 이전 운영 코드: 45b5cba05db6859fc87ec75422a652c70a274694 (v0.28.0). 롤백 시 추가 테이블은 보존합니다.
