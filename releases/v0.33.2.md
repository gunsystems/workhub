# v0.33.2 · 폴더·파일 접근 관리 명칭 통일

- 폴더 권한 현황, 폴더 접근 관리, 파일 접근 관리, 문서함 접근 관리, 그룹 구성원 관리의 대상을 명확히 구분한다. 공동 문서 진입 버튼·목록 메뉴·페이지 제목·현황 이동 버튼·접근 확인·관리자 연결·도움말에 일관되게 적용한다.
- 파일의 권한 안내에서 하위 자료까지 변경되는 것처럼 보이던 문구를 정리한다. 일반 직원의 접근 확인 화면은 관리자 문의를 안내하며 관리자만 접근 관리 버튼을 본다.
- 권한 판정·저장·그룹 구성원·폴더/파일 접근 범위는 변경하지 않는다.
