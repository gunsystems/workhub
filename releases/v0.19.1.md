# v0.19.1 사원카드 사진

- 내 정보와 관리자 직원 카드 화면에서 사진 선택·저장, 기본 이미지로 변경 기능을 추가합니다.
- JPG·PNG·WebP 최대 5MB, 최대 1,600만 화소를 검사하고 EXIF 회전 적용 후 메타데이터 없는 600×760 JPEG로 변환합니다. 카드 이미지 저장 시에도 사진을 넣습니다.
- 파일은 기존 비공개 Drive에 저장하며 본인·관리자만 인증된 경로로 조회합니다. 공개 URL을 만들지 않습니다. 저장소 실패 시 기존 사진은 유지합니다.
- 변경 이력은 사진 표시 여부만 남깁니다. 이전 파일은 물리적으로 삭제하지 않고 최신 버전만 표시합니다.
- 0048_employee_card_photo는 사진 버전 테이블만 추가합니다. 직원·계정·권한·연차는 변경하지 않습니다.

## 확인 방법

계정 메뉴 → 내 정보·사원카드 → 사진 선택 → 사진 저장. 카드의 사진과 PNG 저장 결과를 확인합니다. 사진이 없으면 이름 첫 글자가 표시됩니다.
