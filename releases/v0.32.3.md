# v0.32.3 · 폴더 접근 관리의 구성원 표시

- 접근 관리 그룹 카드에 최근 확인된 구성원을 바로 표시하고, 현재 Microsoft 그룹 구성원을 별도로 재조회하여 수·이름·확인 시각을 표시한다. 기존 한글 이름 연결을 같은 방식으로 적용한다.
- 구성원 없음·확인 중·조회 실패를 구분하고, 실패 시 최근 표시를 지우지 않으며 다시 확인할 수 있다. ‘이 그룹의 구성원 관리’로 바로 이동한다.
- 관리자 그룹과 구성원을 읽기 전용으로 별도 표시한다. 폴더 권한 선택·검토·저장과 실제 접근 검사는 변경하지 않는다. 구성원 조회는 GET/no-store이며 새 권한이나 구성원을 추가하지 않는다.
