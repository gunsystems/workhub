# Workhub v0.9.0 보고 구분·배정 알림·자동 상위자

2026-11-09 · Asia/Seoul

## 변경 사항

- 업무 보고: 일일·주간·월간·개별·기간 보고 구분. 새 보고는 주간 보고가 기본이며 구분에 맞는 날짜를 제안한다. 직접 입력한 날짜와 기존 보고 수정 값은 보존한다. 일일 보고는 하루만 지정한다.
- 보고 목록의 구분 필터, 제출 버전에 보고 구분 보존, 취합 대상 버전의 구분 표시. 과거 보고는 기간 보고로 유지하고 과거 제출 원본은 변경하지 않는다.
- 업무 배정 시 이메일·하이웍스 메신저를 각각 선택하거나 함께 선택할 수 있다. 둘 다 해제해도 시스템 내 업무 확인은 가능하다. 기존 배정 소급 재발송은 하지 않는다. 반복 회차와 인계에도 선택을 적용한다.
- 직속 상위자를 지정하지 않은 직원은 같은 부서의 팀장이 나중에 등록되면 자동 연결한다. 팀장이 없으면 같은 부서의 본부장에게 연결한다. 동일 직책 후보가 여러 명이면 임의 지정하지 않는다. 수동 지정은 보존하고 계정 관리 권한이나 기존 결재선은 변경하지 않는다.
- 업무 접수함은 담당자 확정 전 접수 기록이며, 직접 업무 등록과 별도라는 안내를 보강한다. 접수 후 배정한 요청은 배정 완료 탭에 남고, 배정 완료와 직원의 열람 확인을 구분한다.
- 기존 페이지 도움말에 보고 구분·배정 채널·자동 상위자·접수함 설명을 추가한다. 교육자료는 최종 마무리 단계까지 제작하지 않는다.
- 업무·프로젝트 문서 관리와 외부 저장소는 검토안으로 기록했다. 실제 파일 통합·외부 저장소 연결은 이번 구현에 포함하지 않는다. 상세: [문서 저장소 검토](../DOCUMENT_STORAGE_REVIEW_20261109.md).
