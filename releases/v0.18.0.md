# v0.18.0 퇴사 후속 조치

- 직원 관리 내부에 관리자용 퇴사 처리 목록·등록·항목별 담당자/기한 설정·최종 확인 추가. 별도 관리자 사이드바 항목은 만들지 않음.
- 기본 항목: Workhub 중지, 회사 메일, MS365, 캡스, 업무·자료 인계, 회사 자산 회수. 외부 서비스 삭제나 계정 중지는 자동 실행하지 않음.
- 담당자는 본인 배정 항목만 열람·제출. 전체 퇴사 건 및 다른 담당자의 증빙은 차단. 실제 처리 일시와 제출·검토 시각을 분리함.
- 처리 시작 → 증빙 제출 → 관리자 확인 완료/보완 요청. 파일은 기존 비공개 저장소 사용, PNG/JPG/PDF 20MB 제한, 이미지 안전 미리보기 제공.
- 재제출·검토 기록·이전 증빙 보존, 오래된 화면의 중복 처리는 버전 검사로 차단. 관리자 직접 처리와 해당 없음 사유 기록 지원.
- 모든 항목을 확인해야 최종 완료. 퇴사일 변경·처리 취소는 사유 보존, 외부 시스템 자동 복구 없음.
- 배정/검토/보완 및 기한 임박·지연/미검토 알림: 업무 알림 + 이메일. 전송 메일에는 퇴사 직원명·처리 내용·증빙을 싣지 않고 인증이 필요한 상세 화면 링크 제공. 메일 실패는 DB와 시스템 로그 보존, 불확실한 전송은 자동 재발송하지 않음.
- 기존 직원·업무 데이터는 수정하지 않는 신규 테이블 migration 0045. 실제 퇴사자를 등록하거나 외부 계정을 변경하지 않음.

## 사용자 확인 순서

1. 관리자: 직원 관리 → 퇴사 후속 조치 → 퇴사 처리 등록. 퇴사일·직원을 선택. 실제 처리를 시작할 대상만 등록하세요.
2. 기본 6개 항목의 담당자·기한을 조정. 본인이 처리하려면 관리자로 유지.
3. 담당자: 배정된 후속 조치/업무 알림 → 처리 시작 → 실제 처리 일시·내용·증빙 제출.
4. 관리자: 확인 대기 항목에서 증빙 확인 → 확인 완료, 또는 보완 요청(의견 필수).
5. 완료 전 모든 항목의 확인 상태를 점검하고 최종 완료.

검사·배포·시각 확인 결과는 완료 후 보완합니다.
