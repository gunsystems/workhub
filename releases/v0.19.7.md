# v0.19.7 · 휴가 관리자 준비 마무리

- 직원 공개 전 관리자 미리보기 유지. 직원 알림·실제 연차 자동 부여 없음.
- 1월 1일 현재 근속기간으로 15~25일 참고값 표시. 전년도 출근율 80% 이상 가정이며 확정 권리가 아님. 대표·입사 1년 미만·입사일 미등록·퇴사 예정은 별도 확인.
- 입사 3년 이상부터 최초 1년 초과 매 2년당 1일 가산, 최대 25일 참고. 첫해 월 개근·회계연도 비례분은 자동 확정하지 않음.
- 준비 점검에서 직원 선택 시 연차 설정으로 연결. 해당 연도 원장이 없을 때만 참고값을 기본 입력. 원장이 있으면 추가/차감 차이를 직접 입력해 이중 부여 예방.
- 현황에서 부여·조정/승인 사용/잔여/신청 대기를 분리. 휴무일 변경에 따른 승인 일수 조정을 신규 부여로 잘못 표시하던 집계 보완.
- 직원 권한과 관리자 미리보기 제한 유지. 팀원→팀장→본부장→대표, 본부장 공석 대표 전결. 팀장은 본부장부터, 본부장은 대표에게 신청.
- 최종 승인 때 차감, 취소 최종 승인 때 복원. 기존 연도 기록 보존, 자동 이월 없음.
- 가입 전 직원도 예상 결재라인에 표시하고 계정 인증 필요 상태를 안내. 미인증 본부장을 공석으로 간주해 대표에게 우회하지 않으며 실제 신청은 인증 전 차단.
- 스키마 변경 없음. 실제 직원 연차는 이번 배포에서 생성·변경하지 않음.

## 관리자 확인 순서
1. 직원 관리 → 휴가 관리 → 운영 준비 점검에서 2027년 선택.
2. 직원 입사일·직책·결재 담당자와 공휴일 연결 상태 확인.
3. 직원별 연차 확인에서 계산 참고값과 회사 실제 부여 일수를 검토. 이미 등록했다면 차이만 조정.
4. 부여/사용/잔여/신청 대기 분리 표시 확인. 실제 부여 저장은 관리자가 최종 확인 후 수행.
5. 직원 공개일과 첫해·퇴사 정산 정책은 별도 확정. 현재 일반 직원의 휴가 URL 접근은 계속 차단.
