# v0.30.5 · Office 업로드 결과 판정 보완

- 실제 검증 폴더에 새 DOCX를 업로드할 때 파일은 생성됐지만 보낸 1033바이트와 SharePoint 반환 용량 약 9.1KB가 달라 실패 안내가 표시되는 문제를 발견했습니다. 중복 업로드는 하지 않았습니다.
- SharePoint의 Office 속성 처리로 저장 패키지의 용량이 바뀔 수 있으므로 docx/xlsx/pptx는 정상 HTTP 응답과 사이트·문서함·파일명·파일 형식·양의 정수 저장 용량을 확인합니다. 다른 확장자는 전송/저장 용량 일치 검사를 유지합니다.
- 계정별 위임 권한, 동일 파일명 덮어쓰기 방지, 새 버전 대상 ID/ETag, 리다이렉트 및 쓰기 재시도 차단은 유지합니다. 감사 기록은 공급자가 반환한 저장 용량을 사용합니다.
- 파일 전송 관련 검사 18개 통과. 저장 용량 변경 허용과 비Office/잘못된 용량/다른 파일명/다른 기존 ID 거부 검사 포함.
- Word 웹에서 새 검증 문서의 본문 표시, 편집 모드, 테스트 문구 저장, 재열기 후 문구 유지 확인. 다른 직원 간 공동편집은 사용자 요청으로 직원 동석 시 검증하도록 DEVELOPMENT_STATUS.md와 PRODUCT_ROADMAP.md에 미완료로 기록했습니다.
- 근거: https://learn.microsoft.com/en-us/previous-versions/office/developer/sharepoint-2010/aa543341(v=office.14)
