# Workhub v0.11.0 테스트 가이드

## 시작 위치
왼쪽 업무 등록 → 내 업무 등록 / 업무 요청 / 업무협조 요청.
직접 주소: https://workhub.gunsystems.co.kr/work/register/
요청함: https://workhub.gunsystems.co.kr/intake/?box=sent&state=all

실제 업무나 실제 직원에게 시험 알림이 가지 않도록 담당자·배정 알림 옵션을 먼저 확인하세요. 테스트용 요청은 취소로 이력을 남길 수 있습니다.

## 1. 임원·팀장의 직접 업무 요청
1. 업무 등록 → 업무 요청을 선택합니다.
2. 직원·기한·완료 조건·필요한 결재라인을 정합니다. 배정 시 이메일·메신저 옵션을 선택할 수 있습니다.
3. 업무 접수함 → 내가 보낸 요청 → 배정 완료 또는 전체 기록에서 확인합니다.
4. 직원은 내 업무·업무 현황에서 배정 확인 후 질문·진행 보고·완료 보고를 합니다.
※ 기존에 업무 등록으로 만든 업무는 등록 구분을 소급 변경하지 않습니다.

## 2. 영업팀 → 기술팀 엔지니어 지원 요청
1. 영업 직원 계정으로 업무협조 요청 → 엔지니어 지원 요청을 선택합니다.
2. 지원 팀을 기술팀으로 지정하고 프로젝트·고객사·솔루션·필요 인원·희망 시작/종료일·배정 회신 기한을 작성합니다.
3. 희망 엔지니어는 선택 사항이며 최종 인력 배정이 아닙니다. 참고 자료는 링크로 연결할 수 있습니다. 저장소 열람 권한은 별도로 부여하세요.
4. 요청자는 내가 보낸 요청, 기술팀장은 우리 팀이 받은 요청에서 확인합니다. 관련 없는 팀이나 배정 전 일반 팀원에게는 원본 요청이 표시되지 않아야 합니다.
5. 접수 확인·일정/인력 협의·보완 요청을 각각 사유와 함께 남깁니다. 요청자는 요청 내용 수정·보완에서 보완하고 변경 전 정보가 이력에 남는지 확인합니다.
6. 배정 화면에서 희망 기간과 겹치는 팀 업무를 확인하고 총괄 담당자·공동 수행자·결재라인을 정합니다. 요청 인원보다 적거나 희망 기간과 다르면 조정 사유를 입력해야 합니다.
7. 배정하면 기존 업무로 연결됩니다. 요청자도 참조자로 해당 업무를 볼 수 있습니다. 관련 프로젝트 전체를 무조건 열람하도록 권한을 부여하지 않습니다.
8. 원본 요청 → 투입 기간·역할 수정에서 수행자별 역할과 업무 기간 안의 투입 기간을 기록합니다. 변경 사유가 필요합니다.
9. 직원은 기존 업무 화면에서 수행·완료 보고하고 지정 결재자가 승인합니다. 이후 요청자가 원본 요청에서 결과 확인 완료를 남깁니다.
10. 추가 지원이 필요하면 추가 지원 요청을 눌러 새 요청을 연결합니다. 완료된 업무는 그대로 보존됩니다. 새 요청의 희망 기간·프로젝트 기간을 확인하고 필요하면 보완하세요.

## 3. 권한·취소·공석 확인
- 수신 팀장/부서 관리자와 임원·관리자가 배정합니다. 요청자가 다른 팀 직원을 희망 인원으로 골랐다는 이유로 자동 배정되지 않습니다.
- 팀장 공석이면 같은 팀 접수 대행자를 선택할 수 있습니다. 대행자는 접수·협의만 하며 인력 배정·지원 불가 결정 권한은 얻지 않습니다. 책임자가 없으면 관리자 내부 알림 및 조치 필요 목록에서 확인합니다.
- 배정 전에는 요청 취소 또는 지원 불가 사유를 남길 수 있습니다. 배정 후 변경·취소는 연결된 수행 업무에서 처리합니다.
- 같은 화면을 두 창에서 처리하면 오래된 내용으로 덮어쓰지 않도록 안내해야 합니다. 같은 요청에서 배정 버튼을 다시 눌러도 업무가 중복 생성되지 않아야 합니다.

## 알림과 현재 범위
- 배정 전 접수·협의·보완은 Workhub 내부 알림입니다. 배정 확정 후에는 기존 이메일·하이웍스 메신저 옵션을 사용합니다.
- 개인 투입 기간은 요청의 인력 계획 기록입니다. 캘린더는 현재 수행 업무의 공통 기간을 사용합니다.
- 업무 겹침 경고는 휴가·실제 가용시간·전문 기술 매칭을 계산한 결과가 아닙니다.
- 협조 요청 1건은 공동 업무 1건으로 연결됩니다. 여러 팀이 별도 책임으로 처리해야 한다면 팀별 요청을 만들어 프로젝트에 연결합니다.
- 외부 파일 저장소·새 자동 인력 배정 기능은 이번 범위에 포함하지 않습니다.
