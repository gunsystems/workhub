# v0.34.8 — 표준 공동문서 초기 생성·권한 적용 실행

- 관리자 적용 예정표에서 실제 문서함·그룹·구성원을 재조회해 적용 검토 기록을 준비합니다. 이 준비 단계는 SharePoint 자료나 권한을 변경하지 않습니다.
- 새 전사공통 문서함, 표준 폴더 51개, 삭제불가 기여 권한, 빈 영업·경영지원 그룹과 대표 경영진 그룹을 단계별로 생성합니다.
- 기존 전 직원·보안기술팀·관리자 그룹은 구성원을 변경하지 않고 새 폴더에 연결합니다. 현재 대표임이 확인된 관리자 연결만 경영진 초기 구성을 실행할 수 있습니다.
- 직접 생성한 영역의 ★ 지점에만 그룹 권한을 적용하고 읽기·기여·삭제불가 기여·관리를 검증합니다. 기존 경로 충돌은 자동 채택·덮어쓰기 없이 중단합니다.
- 사이트 공통 잠금으로 다른 구성원·폴더 권한 변경과 충돌을 방지합니다. SharePoint의 Limited Access는 콘텐츠 접근 권한과 구분합니다.
- 각 단계의 실행 기록과 시스템 로그를 남깁니다. 불명확한 외부 적용 결과는 자동 재실행하지 않습니다.
- 프로젝트 템플릿의 실제 생성/종료, 벤더 설정 화면, 권한 요청·승인 기능은 이 릴리스의 완료 범위가 아닙니다.

검증: 관련 서버 검사 144개, 실행 화면의 중복 클릭·순차 진행·오류/로그인 전환 시 중단 검사 통과. 추가 명시 확인 검사도 수행합니다.
