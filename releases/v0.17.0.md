# v0.17.0 팀 주간보고 자동 그룹핑

## 변경 내용
- 업무 보고에서 팀 보고 취합으로 진입하면 같은 주의 최신 유효 제출본을 골라 분류 초안을 만듭니다. 팀장은 팀 범위, 본부장·임원·시스템 관리자는 자신에게 제출된 보고를 기본으로 취합합니다.
- 고객사, 벤더사, 팀 운영·기타, 미분류 구역으로 이번 주 진행 업무·차주 예정 업무·이슈 내용을 정리합니다.
- 동일한 내용만 합치고 모든 작성자·제출 버전 출처를 남깁니다. 진행률·의견이 다른 내용은 유지합니다.
- 팀장이 정리한 그룹 제목과 수정 내용을 본부장 재취합에서도 유지합니다. 원본 제출 버전 연결도 보존합니다.
- 추가 취합은 미리보기와 명시적 적용 단계를 거치며 직접 작성 중인 내용은 자동으로 덮어쓰지 않습니다. 첨부 선택 중에는 재취합으로 파일 선택이 사라지지 않도록 안내합니다.
- 업무에 벤더사·솔루션·보고 분류를 추가하고 기존 고객사 필드를 보고 분류 영역에 배치합니다. 반복 업무에도 분류 정보를 복사하고 협조 요청의 솔루션 정보를 업무로 전달합니다.
- 제출 시 분류 정보를 함께 보존합니다. 이전 제출본에 정보가 없으면 조회 가능한 현재 업무의 분류만 참고하며 이를 화면에 안내합니다.

## 범위와 한계
- 내용의 의미를 바꾸는 자동 요약이나 회사명 추측은 하지 않습니다. 정보가 없는 문장은 미분류로 남아 사용자가 보완합니다.
- 같은 회사의 대소문자·띄어쓰기 차이만 묶으며 회사명 별칭을 임의로 동일시하지 않습니다.
- 기존 업무·보고 본문은 일괄 수정하지 않습니다. 실제 업무 이력에 영향을 주지 않는 새 초안 생성 기능입니다.
- 휴가 승인·휴가 관리의 공개 범위와 점수 산식은 변경하지 않습니다. 캘린더 미등록 추적은 별도 후속 항목입니다.
- 마이그레이션0041은 Task에 선택적 분류 필드를 추가합니다. 기존 버전으로 코드 롤백할 때 추가 필드를 삭제할 필요는 없습니다.
