# v0.24.4 · 업무 등록 흐름과 미팅 입력 보완

- 신규 업무에서 관리 방식을 간단 업무로 바꾸면 같은 화면에서 날짜·결재·공동 수행 입력을 숨깁니다. 다시 변경해도 제목·내용·담당자·첨부·결재자 입력을 유지합니다.
- 간단 업무는 검증된 직원에게만 등록하며 기존 요청 확인→결과 회신→요청자 완료 절차를 유지합니다. 기존 업무나 인력 배정 요청은 간단 업무로 변환하지 않습니다.
- 간단 업무 왼쪽 주 메뉴를 제거합니다. 업무 등록, 내 업무 요약과 기존 알림 링크로 접근합니다.
- 미팅 접속 링크 입력 예시·검사 범위를 안내합니다. 오프라인·Teams 자동 생성에서는 사용하지 않는 링크 검사를 건너뜁니다.
- 실제 Microsoft 연결·외부 초대 발송 검증은 서비스 장애 복구 후 진행합니다. 로고 추가 변경은 보류합니다.

## 검증
- 관련 Django 검사 46개 통과. 간단 업무 생성·오류 유지·메뉴 접근과 미팅 숨김 링크 검사를 포함합니다.
- 업무 관리 방식 전환 시 파일·내용·결재자 유지와 비해당 필수 입력 제외 JavaScript 검사 통과.
- 전체 CI 및 운영 화면 확인 후 배포 이력에 결과 기록.
