# v0.31.1 · 서류 신청 입력·기간 안내와 발급 메일 개선

- 기타 서류를 선택한 경우에만 필요한 서류명을 활성화하고 필수로 입력한다. 다른 종류의 위조된 서류명도 서버에서 무시한다.
- 대상 기간을 ‘서류에 포함할 기간’으로 표시한다. 급여명세서의 급여 기간·경력증명서의 기재 근무 기간이라는 예시와 발급일·휴가 기간이 아니라는 안내를 제공한다. 기간 지정이 불필요한 재직증명서는 비워 둘 수 있다.
- 발급 완료·결과·접수 메일을 기존 전자결재 메일과 같은 회사 헤더·안내 카드·초록색 버튼으로 표시한다. 이메일에는 개인 서류·용도·내용을 넣지 않고 로그인 링크만 전달한다. 기존 메일은 재발송하지 않는다.
- 신청 화면에 본인·관리자·지정 발급담당자 열람 범위를 안내한다. 기존 ACL·재배정·발급 취소·메일 대상 재검사 정책은 유지한다.
- 서버 양식의 비활성화/위조 입력 방지 검사와 JS 선택 전환 검사를 추가했다. migration 없음.
