# v0.21.0 · 휴가 전자결재 개발·테스트 공개

- 활성 직원 계정의 휴가 신청·결재·휴가 현황 공개. 관리자 직원 선택은 조회 미리보기 유지.
- 직원은 본인 신청, 결재자는 현재 본인 차례만 승인·반려. 다른 직원 지정 URL로 대리 신청·승인 불가.
- 대표 본인 휴가는 대표 단일 단계 셀프 결재. 다른 직원 휴가는 기존 순차 결재 유지.
- 대표·본부장은 전사, 팀장은 팀, 일반 직원은 본인 연차·휴가 조회. 부여·조정과 휴일 운영 설정은 관리자 전용 유지.
- 결재 단계·최종 결과 업무 알림과 메일 활성화. 요청 발송은 기존 큐에서 처리, 계정/메일/현재 단계 재확인.
- 실제 연차 자동 부여·계정 활성화·신청 대리 작성은 수행하지 않음. 실제 저장은 운영 DB에 기록되는 개발·테스트 공개임.
