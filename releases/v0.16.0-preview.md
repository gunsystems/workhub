# v0.16.0-preview — 직원·휴가 관리자 준비 화면

## 공개 범위
관리자(is_superuser)에게만 휴가 관리 · 준비 메뉴를 표시한다. 일반 직원·팀장·임원·서브관리자는 목록/신청/상세/설정 GET·POST 모두 403. 정식 공개일은 별도 결정한다.

## 제공
- 직원 입사일/퇴사일/사번 별도 관리. 기존 이름·부서·직책·재직상태는 직원 관리 유지.
- 연도별 부여/추가/차감 원장과 변경 감사 기록. 같은 요청 중복 제출 시 재부여 방지.
- 월~금, 오전·오후 반차 0.5일, 관리자가 등록한 공휴일·회사 휴무일 제외.
- 휴가 처리 엔진: 신청 → 팀장 → 본부장 → 대표, 본부장 공석은 대표 전결로 두 단계 동시 승인. 결재자 스냅샷 보존.
- 최종 승인 전 차감 없음. 취소 결재 완료 시 1회 복원. 회수/반려/재취소와 stale revision 차단.
- 잔여 초과 허용, 초과분 표시 및 결재 의견 필수. 신청 기간 중복 방지. 연도 간 신청 분리.
- 페이지별 도움말. 신청 사유·결재 이력은 권한 밖 사용자에게 제공하지 않음.

## 아직 제공하지 않는 기능
- 일반 직원에게 신청/결재 공개, 자동 연차 계산/월 개근 판정, 공휴일 자동 수집.
- 실직원 메일·하이웍스 알림, 업무/외부 캘린더 반영, 엑셀 입출력.
- 대표 본인 신청, 대결/결재자 변경, 연도간 신청 일괄분할, 시간차·특별휴가, CAPS.
- 법정 일수와 회계연도 비교 계산 및 소멸/정산 자동화. 실제 부여량은 회사 확인 후 관리자가 입력.

## 확정 운영 기준
2027 정식 오픈 목표. 1월1일 회계연도. 기본 근무10:00~17:00/점심1시간. 유연한 초과 사용 승인. 기존 근태 숫자 이관/평가 제외. 과거 휴가는 별도 보관.

## 데이터/롤백
0037은 신규 테이블만 생성하며 기존 직원·업무·인증 정보를 수정하지 않는다. 기존 데이터로 직원 입사일이나 연차를 자동 입력하지 않는다. 이전 코드로 롤백 시 신규 테이블은 유지해 기록 손실을 피한다. 정식 공개는 별도 버전으로 진행한다.
