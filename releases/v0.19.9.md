# v0.19.9 · 후속 조치 처리 기록 요약

- 처리 기록을 카드에서 간결한 목록으로 변경. 항목명·대상 직원·확인 결과·확인 시각만 표시.
- 내용 확인 버튼과 상세 설명은 기록 목록에서 제외. 처리/취소 확인 탭과 원본 이력 보존.
- 취소 확인 또는 관리자 확인의 최신 시각 순서로 정렬. 예전 기록에 시각이 없으면 명시.
- 모바일에서 항목명과 대상 직원은 위쪽, 결과와 시각은 아래쪽으로 배치.
- 데이터 변경/스키마 변경 없음.

- 업무 알림에서도 발송 당시 문구 대신 항목명·대상 직원·현재 상태 표시. 취소 확인/관리자 확인 완료 항목은 새 알림 표시와 배정 항목 확인 버튼을 제거하며 원본 알림 기록은 보존.
