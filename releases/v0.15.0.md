# v0.15.0 · 간단 업무와 자료 전달

## 변경 내용
- 관리 방식: 보고 업무 / 일반 업무. 짧은 요청은 별도 간단 업무 입력 화면으로 연결합니다.
- 간단 업무: 날짜·진행률·결재라인 없이 담당자에게 전달 → 요청 확인 → 결과 회신 → 요청자 확인 완료.
- 전달·요청 확인·최근 결과 회신·확인 완료 시각과 처리 이력을 보존합니다. 추가 확인 요청과 사유 있는 취소를 지원합니다.
- 처음 전달할 때 파일(최대 20MB)과 기사·웹페이지 링크를 함께 등록할 수 있습니다. 전달 후 업무자료에서 참고 파일·결과물·링크를 추가합니다. 파일은 기존 Google Drive 저장소를 사용하고 Workhub 권한으로 다운로드합니다.
- 간단 업무는 업무 현황의 ‘간단 업무’ 버튼과 업무 등록에서 확인합니다. 요청자·담당자 외 팀 관리자·임원은 기존 권한 범위에서 조회하며 임의 회신·완료 권한은 갖지 않습니다.
- 이메일·하이웍스 알림은 트랜잭션 아웃박스로 전달하며 불확실한 발송을 자동 반복하지 않습니다. 수신 자격·이메일·하이웍스 알림 설정을 발송 전 재확인합니다.
- ‘하이웍스로 배정 알림’ 명칭 적용. 설문 제출 완료 안내의 내부 독려 문구 제거. 공지·설문 작성 버튼 간격·높이 통일.

## 동작 범위
- 간단 업무는 시작일·마감일이 없으므로 캘린더·마감 지연·기존 수행 점수 집계에 포함하지 않습니다.
- 대기 시간은 달력 시간입니다. 근무 시간 기준 지연 판정이나 자동 독려는 이번 범위가 아닙니다.
- 파일당 20MB, 업무자료 최대 100개. 링크는 외부 사이트에서 별도 권한이 필요할 수 있습니다.
- 기존 업무를 간단 업무로 변환하거나 영구 삭제하는 기능은 제공하지 않습니다. 취소 이력을 보존합니다.

## 확인 절차
1. 업무 등록 → 간단 업무에서 본인 또는 동의한 테스트 직원에게 요청을 전달합니다. 문서와 기사 링크를 추가합니다.
2. 담당자는 요청 확인 전 결과 회신이 불가능한지 확인하고, 요청 확인 후 자료를 열어 결과를 회신합니다.
3. 요청자는 추가 확인 요청 → 재회신 또는 확인 완료로 종료합니다.
4. 업무 현황 → 간단 업무에서 보낸 업무·받은 업무·완료/취소 상태를 확인합니다.
5. 승인되지 않은 다른 직원 계정에서 직접 요청 URL·파일 다운로드 URL이 열리지 않는지 확인합니다.
6. 설문 제출 완료 화면 안내와 공지·설문 작성 하단 버튼의 PC·모바일 배치를 확인합니다.
