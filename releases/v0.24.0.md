# v0.24.0 · 미팅 간편 등록과 Teams 자동 생성 준비

미팅은 날짜·시작 시간·소요시간을 한 번 입력합니다. 사내·외부·온라인·병행을 선택하고 필요한 장소와 접속 정보만 표시합니다. 참석자는 Workhub에서 참석·미정·불참으로 응답합니다. 시간 변경 시 응답을 다시 확인하며, 주최자는 종료 후 선택적으로 결과를 기록합니다. 자료는 기존 비공개 업무자료 저장소로 연결합니다.

미팅은 기존 업무·캘린더·업무보고의 동일 Task를 사용하되 일반 업무 배정 확인·진행률·성과 점수·마감 독촉과 구분합니다. 새 왼쪽 메뉴를 추가하지 않고 업무 등록·캘린더·기존 업무 요청 화면에서 접근합니다. 초대·변경·취소는 업무 알림·메일·설정된 하이웍스 알림으로 전달하고 시작 15분 전에는 프로그램·하이웍스 알림을 생성합니다.

Teams 자동 생성은 Microsoft Graph 위임 인증과 일정 API로 구현합니다. 주최자만 회사 계정을 연결합니다. 생성·변경·취소와 외부 참석자 초대를 지원하며, 기존 이벤트 ID와 고정 transactionId로 중복을 방지합니다. 연결 대기·오류·결과 불명을 구분합니다. 실제 회사 Microsoft 앱 설정과 계정 연결을 마치기 전에는 Teams 운영 검증 완료로 보지 않습니다.

## 제한과 운영 확인

- Workhub 참석 응답과 Outlook 초대 응답은 분리되어 있습니다.
- 외부 참석자 자동 초대는 Teams 자동 생성에서 제공하며 Workhub 내부 자료 접근은 허용하지 않습니다.
- 반복 미팅, 회의실 예약, 외부 캘린더 빈 시간 조회는 이번 범위에 포함하지 않습니다.
- 기존 업무 종류가 미팅인 일반 업무는 자동 변환하지 않습니다.
- Microsoft 앱 등록·연결과 실제 초대 수신 확인이 남아 있습니다. 설정 안내: `MICROSOFT_MEETINGS_SETUP.md`.

## 검증

전체 회귀 검사와 집중 검사, 배포·화면 확인 결과를 기록합니다. Teams 외부 API 검사는 모의 응답이며 실제 회사 계정 연결 검증과 구분합니다.
