# v0.17.3 보고 구분 명칭과 기간 안내 정리

- 개별 보고 → 건별 보고, 기간 보고 → 기간 지정 보고로 변경합니다.
- 보고 구분 선택 목록·조회 조건·안내·사용 가이드·제출 이력 표시를 통일합니다.
- 기간 지정 보고는 시작일과 종료일을 직접 선택해 작성하는 보고로 설명합니다.
- 기본 기간 안내: ‘일일·건별 보고는 오늘, 주간 보고는 이번 주, 월간 보고는 이번 달을 기본으로 설정합니다. 보고 기간은 직접 변경할 수 있습니다.’
- 저장 값 individual·period, 기간 계산 및 기존 제출 스냅샷은 유지합니다. 이전 스냅샷의 명칭은 화면에서만 새 명칭으로 표시합니다.
- 마이그레이션0044는 선택 항목의 표시 이름만 변경하며 기존 보고를 일괄 수정하지 않습니다.

- 간단 업무 검색 필터를 공통 workspace-toolbar로 통일합니다. 입력칸·선택 박스·조회 버튼은 공통 44px 높이와 글꼴·테두리를 사용하며, 좁은 화면에서는 2열·1열로 배치합니다.
