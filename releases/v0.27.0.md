# v0.27.0 · 대용량 문서함의 단계별 목록 조회

- 폴더 목록을 한 번에 50개씩 불러오며 다음 페이지는 더 보기로 조회합니다. 화면 표시 전에 최대 500개를 모두 수집하던 조회를 제거했습니다.
- 이름순·이름 역순·최근 수정순을 Microsoft 조회에 적용합니다.
- 현재 폴더의 이름 검색은 50개 항목씩 확인합니다. 아직 검색하지 않은 항목이 있으면 다음 항목 검색과 확인 개수를 표시합니다. 하위 폴더나 문서 내용까지 검색하는 SharePoint 전체 검색과 구분합니다.
- 폴더·문서함 이동과 조회는 문서함 영역만 갱신하며 로딩·실패 상태를 표시합니다. 뒤로/앞으로 이동 및 JavaScript를 사용할 수 없는 경우의 일반 링크를 유지합니다.
- 다음 페이지 주소는 암호화하고 15분 만료·직원 연결·회사 사이트·폴더·검색어·정렬 조건에 묶습니다. 조회마다 Microsoft 본인 권한을 재확인하고 권한 오류는 기존 목록을 교체합니다.
- 파일·폴더 관리의 변경 권한과 빈 폴더 삭제 제한은 유지합니다.

## 검증

- 50개 첫 화면에서 다음 페이지를 자동 조회하지 않는지, 2페이지 연결·주소 위변조·사용자/조건 격리·만료·선택 사이트 범위를 검사합니다.
- 브라우저 스크립트의 영역 갱신·추가 목록 중복 제거·인증 만료·실패·요청 경합을 검사합니다.
- 배포 및 실제 PC·모바일 점검 후 최종 결과를 기록합니다.
