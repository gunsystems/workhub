# v0.33.4 · 직원 문서 계정 연결과 오류 복귀 보완

- 공동 문서의 폼 화면은 same-origin Referrer-Policy로 정상 HTTPS POST의 출처 확인을 지원한다. OAuth 콜백·외부 문서 열기의 no-referrer는 유지한다.
- CSRF 거절 시 문서·관리자·Teams·Google 연결의 다시 시도 링크를 POST 전용 주소 대신 연결 설정 GET 화면으로 보낸다. 오래된 문서 연결 GET 주소도 안전한 목록 화면으로 복귀하며 OAuth는 시작하지 않는다.
- CSRF·Origin/Referer·계정별 OAuth state/PKCE·회사 이메일 일치·저장소 권한 검사는 유지한다. 거절된 요청은 자동 재전송하지 않는다.
- 직원별 HTTPS Referer-only 요청, 오래된 토큰 복귀·새 POST, 악성 Origin·쿠키 누락 거절·GET 무변경을 검증한다. 실패 진단에는 제한된 흐름 이름·오류 분류만 기록한다.
