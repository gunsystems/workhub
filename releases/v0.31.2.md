# v0.31.2 · 팀·업무 문서 그룹 구성원 관리

- 공동 문서의 관리자 메뉴에서 팀·업무 구성원 관리로 바로 이동한다.
- 기존 사이트 그룹을 명시적인 검토·적용으로 관리 대상으로 연결한다. 그룹 생성 위치와 무관하게 직원 검색·부서 필터·복수 선택으로 추가와 제외를 관리한다.
- 관리 연결 자체는 그룹 구성원이나 문서 접근 권한을 변경하지 않는다. 사이트의 기본 소유자·구성원·방문자 그룹은 ID로 보호하며 이름을 바꿔도 보호한다.
- 서버 관리자 검사, CSRF, 일회성 검토, 변경 사유, 사이트 잠금, 적용 직전 상태 재검사와 감사 로그를 유지한다. 연결된 모든 폴더에 미치는 영향 및 다른 경로의 접근이 남을 수 있음을 설명한다.
- DB migration 없음. 실제 직원 권한의 일괄 변경 없음.
