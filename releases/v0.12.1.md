# Workhub v0.12.1 — 기존 업무의 자료 관리 호환

- 이전 버전에서 등록한 업무에도 업무자료 목록과 자료 추가 버튼을 표시합니다.
- 구형 업무 화면의 ‘Google 캘린더에 마감일 등록’을 ‘Google 캘린더에 일정 등록’으로 통일합니다.
- 저장소 확인은 공유 드라이브 자체와 파일 추가 권한을 함께 확인하고 실제 공유 드라이브 이름을 표시합니다.
- 인증 파일 누락, JSON 형식 오류, 서비스 계정 키 형식 오류를 구분해 관리자에게 안내합니다. 키 내용은 표시하지 않습니다.
- UTF-8 BOM이 있는 JSON 및 경로 앞뒤 공백을 처리합니다.

스키마 변경 없음. 로그인·OTP·업무 정보·기존 첨부 원본은 변경하지 않습니다.

확인: 기존 업무 상세의 업무자료 표시, 정상·누락·잘못된 인증 JSON 처리, 새 파일 등록·다운로드·권한 차단.
