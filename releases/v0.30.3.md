# v0.30.3 · 공동 문서 폴더 조회 왕복 감소 (검증 준비)

- 사용자 위임 토큰으로 문서함 접근을 새로 확인한 뒤, 현재 폴더 정보와 하위 항목 50개를 Graph 읽기 전용 JSON batch 한 번으로 요청합니다. 논리적 Graph 조회 수는 같고 서버→Microsoft HTTP 왕복이 두 번에서 한 번으로 줄어듭니다.
- 각 하위 응답의 ID·상태·본문, 사이트·문서함·폴더 경계와 페이지 토큰을 검증합니다. 한 응답이라도 실패하면 목록을 표시하지 않으며 거부 시 우회 재시도하지 않습니다. 상위 경로 검증도 완료된 뒤 화면에 게시합니다.
- 목록·권한 캐시는 추가하지 않았고 새 탐색마다 현재 권한으로 조회합니다. 현재 요청에서 검증한 폴더 정보만 같은 요청의 경로 확인에 재사용합니다.
- 진단: Server-Timing과 서버 로그에 연결·목록·경로·렌더링·전체 시간(밀리초), 브라우저 콘솔에 문서 영역 갱신 시간과 같은 숫자 지표만 기록합니다. 이름·경로·사용자·토큰은 기록하지 않습니다.
- 검증: 문서 연결/탐색/HTTP 경계 검사 63개 및 JavaScript 탐색 회귀 검사 통과. Microsoft 공식 JSON batching 명세의 응답별 상태 확인과 ID 대응 규칙을 적용했습니다.
- 운영 전후 실측은 아직 미완료입니다. 로그인된 동일 계정·동일 폴더에서 최초 1회와 반복 5회 이상을 분리하고, 성공 응답의 중앙값과 범위를 비교할 예정입니다. 운영 반영과 실제 개선 수치는 실측 후 기록해야 합니다.
