# v0.20.0 · 전자결재 관리자 미리보기

- 전자결재 단일 메뉴와 내 휴가·내 신청·결재함·휴가 현황 탭 구성.
- 관리자 전용 조회 미리보기 유지. 직원 선택은 화면 조회 용도이며 대리 신청·승인 권한을 부여하지 않음.
- 결재함은 현재 결재 차례 기준. 휴가 현황은 승인된 신청만 표시하고 신청 사유를 노출하지 않음.
- 연차 부여·조정은 직원 관리에 유지. 직원 공개·자동 부여·실제 계정 활성화는 수행하지 않음.
- 향후 전자결재 양식으로 경비처리(지출결의서), 품의서 추가 예정. 양식별 입력과 결재 정책은 별도 검토. 현재 미구현 메뉴는 표시하지 않음.
- 기존 휴가 결재·차감 로직과 스키마 변경 없음.

## 메뉴 및 향후 확장

- 전자결재: 직원이 쓰는 신청·진행 확인·결재 대기 화면을 한곳에 구성.
- 직원 관리 > 휴가 관리: 관리자 연차 부여·조정·휴무일 설정 유지.
- 경비처리(지출결의서): 비용 항목·금액·증빙·결재선·지급 상태를 별도 설계 예정.
- 품의서: 목적·내용·예상 비용·첨부·결재선을 별도 설계 예정.
- 공통 확장 대상: 문서 종류, 신청 내역, 결재함, 결재 이력. 해당 양식은 아직 구현하지 않음.
