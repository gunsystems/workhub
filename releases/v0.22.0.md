# v0.22.0 · 품의 결재·처리 내역·휴가 캘린더

- 전자결재 → 품의서: 구매·비용, 교육·자격증, 복지, 출장·고객 업무, 계약·갱신, 기타.
- 사용 전 승인 / 사용 후 비용 청구 구분. 임시 저장 → 증빙 추가 → 제출 → 순차 결재.
- 대표 본인 품의 셀프 결재 허용(사용자 확정). 일반 직원은 팀장→본부장→대표, 본부장 공석은 대표 전결.
- 제출 후 본문·증빙 변경 잠금. 회수·반려 후 수정·재제출, 이전 결재와 제출 스냅샷 보존.
- 본인의 승인된 사전 품의에 비용 청구 연결. 대기·승인된 누적 청구액 초과 방지.
- 승인과 지급 기록 분리. 실제 지급 후 시스템 관리자가 근거와 함께 기록하며 송금하지 않음.
- 현재 결재 차례만 메뉴 숫자·결재함에 표시. 이메일 outbox와 업무 알림 연결.
- 전자결재 → 처리 내역: 휴가·품의 승인/반려/회수 및 이미 결재한 진행 건, 연도별 조회·페이지 구분.
- 승인된 휴가를 업무 캘린더에 신청자 이름·휴가 종류로 직접 표시. 취소 승인 시 제외. 업무·평가 데이터 중복 생성 없음.
- 날짜 범위: 시작일 변경 시 종료일이 비었거나 앞선 경우 보정, 사용자가 정한 이후 종료일 유지.
- 사원카드 사진 원본은 기존 Drive 유지. 서버에 최대 1시간 캐시, 매 요청 권한 확인, 사진 교체·삭제 즉시 최신 리비전 적용.

## 확인 경로
1. 직원 계정 → 전자결재 → 품의서 → 품의서 작성 → 임시 저장.
2. 증빙 파일/링크 추가 → 결재 제출 → 결재자 결재함에서 승인/반려.
3. 처리 내역에서 완료·반려·회수 및 본인이 처리한 문서 확인.
4. 휴가 최종 승인 후 업무 캘린더에서 신청자 이름과 휴가 종류 확인.
