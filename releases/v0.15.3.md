# v0.15.3 · 간단 업무 카드 정렬과 반응형 점검

- 간단 업무 카드와 내부 제목에 중복 적용된 여백을 제거합니다. 제목·상태·빈 목록을 같은 왼쪽 기준선으로 맞추고, 0건 영역의 불필요한 높이를 줄입니다. 모바일 전체 보기 버튼은 줄을 나눠 표시합니다.
- 조회·업무 상태·평가·계정 권한에는 변경이 없습니다. DB migration 없음.
- 이상건 세션에서 주요 12개 화면을 360/390/768/1024/1366/1920px, 총 72조합으로 점검했습니다. 내 업무, 업무 현황, 업무 등록, 개인 보드, 캘린더, 보고 작성, 간단 업무 목록·등록·상세, 협조 요청 등록, 프로젝트, 보고 목록.
- 점검 항목: 페이지 가로 넘침, 주요 입력칸·버튼의 화면 이탈, 일반 select의 비정상적 높이. 표·칸반 보드의 내부 가로 스크롤은 별도로 구분했습니다. 발견된 정렬 문제는 이번 수정 대상인 간단 업무 카드였습니다.
- 모바일 개인 보드·캘린더 시각 배치도 확인했습니다. 이는 데스크톱 브라우저의 뷰포트 검사이며 실제 iPhone Safari/Android 키보드·사진 선택, 관리자 전용 화면, 모든 입력 오류·긴 데이터 조합을 전부 검증한 결과는 아닙니다.

배포 후 간단 업무 카드의 수정된 PC·모바일 배치와 반영 정보를 추가 기록합니다.
