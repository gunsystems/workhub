# v0.26.2 · 공동 문서 폴더 이동 조회 최적화

- 직원별 Microsoft 인증 토큰을 실제 유효기간보다 60초 일찍 만료시키고 최대 5분 동안 재사용합니다. 암호화한 토큰만 프로세스 메모리에 최대 128개 보관하며 서버 재시작 시 사라집니다.
- 계정 연결·이메일·사이트·앱·인증정보 변경 시 재사용하지 않습니다. 사용자 본인의 문서함 목록과 접근 권한은 Microsoft에 매 요청 다시 확인하며 서버 앱 권한으로 우회하지 않습니다.
- 같은 화면 요청 안에서 이미 확인한 폴더 정보를 다시 조회하지 않습니다. 다른 화면 요청에서는 새로 조회하므로 이름 변경과 삭제 확인을 이전 화면의 정보로 처리하지 않습니다.
- 문서·폴더 목록이나 접근 권한 결과를 사용자 사이에서 공유하거나 장기 저장하지 않습니다.

## 검증

- 인증 재사용 중에도 사이트 권한 회수 오류가 차단되는지, 인증정보 회전 시 재발급하는지 검사.
- 토큰 만료·최대 보관 개수와 요청 간 폴더 정보 재조회 검사.
- 실제 체감 속도는 배포 후 로그인 상태에서 추가 확인합니다. Microsoft 응답 대기 자체를 제거하는 변경은 아닙니다.
