# Workhub v0.9.5 업무 처리·확인 항목 배치와 설명

2026-11-09 · Asia/Seoul

- 기본 배정 확인·진행 보고·수행 완료·질문/결재 버튼을 먼저 표시하고, 일정/관리 기능 및 확인 항목을 뒤에 분리.
- 확인 항목 목록 뒤에 추가 버튼 배치. 필수/선택과 미확인/확인 완료를 구분하고 행별 확인하기/확인 취소 문구 사용.

- 기존 업무 상세에도 기본 처리 → 확인 항목 순서 및 같은 설명 아이콘 적용. 기존 업무 처리/수정/확인 권한과 필수 확인 완료 조건, 상태별 노출 조건은 유지.
- 템플릿 렌더링에서 배치 순서·필수/선택·설명 연결·읽기 전용 제어 확인. DB migration 없음. 실제 사용자 업무를 변경하거나 테스트 알림을 발송하지 않음.
- 업무 흐름·통합 업무·운영·권한 관련 기존 검사 66개 통과. 시스템 검사 이상 없음. 배포 결과는 확인 후 기록.
