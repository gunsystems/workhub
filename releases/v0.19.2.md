# v0.19.2 내 정보 화면 정리·개인 주소·근속기간

- 사원카드의 사진·이름을 확대하고 밝은 얇은 사진 테두리·은은한 그림자·일관된 모서리를 적용합니다. PNG 저장 이미지에도 같은 비율과 테두리를 적용합니다.
- 내 정보를 사원카드 / 기본 정보 / 개인 정보로 구분합니다. 사진 변경과 주소 입력은 펼침 방식으로 정리합니다.
- 입사일 기준 만 근속 연·월을 자동 표시합니다. 퇴사일이 있으면 그 날짜까지, 미래 입사일은 입사 예정으로 표시합니다.
- 우편번호·기본 주소·상세 주소를 선택 입력합니다. 본인과 관리자가 조회·수정할 수 있으며 다른 직원·서브 관리자에게 공개하지 않습니다. 주소는 카드 PNG 데이터에 포함하지 않습니다.
- 주소 변경은 필드 이름만 감사 로그에 기록하며 원문은 기록하지 않습니다. 화면 간 변경 충돌 시 덮어쓰지 않고 최신 정보 확인을 안내합니다.
- 0049_employee_private_address는 별도 주소 테이블만 추가합니다. 기존 계정·사진·입사일·연차 데이터를 변경하지 않습니다.

## 확인 방법

계정 메뉴 → 내 정보·사원카드 → 근속기간 확인, 개인 정보의 주소 등록/수정 → 주소 저장. 관리자는 직원 관리의 정보·사원카드에서 같은 항목을 수정합니다.
