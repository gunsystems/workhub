# Workhub v0.8.0 업데이트

2026-11-09 · Asia/Seoul · 운영 배포 완료 · 실제 공지 수신 테스트 대기

## 업무 등록

새 업무 등록 화면에서 시작일과 시작 시간을 현재 한국 날짜·시간으로 미리 채웁니다. 등록자가 다른 값으로 바꿀 수 있습니다. 기존 업무 수정이나 입력 오류 후 재표시에서는 저장·입력한 값을 유지합니다. 시작 시간은 별도 선택 입력으로 보존하며 기존 데이터에 임의의 시각을 넣지 않습니다. 날짜만 관리하려면 시간은 비울 수 있습니다. 정기 업무 설정의 기본 시각에도 이 시작 시간을 사용합니다.

필수 입력은 ‘필수’ 배지로 표시하고 예약·대상 선택 등 조건부 필수도 안내합니다. 보고 업무는 결재자 1명 이상 또는 결재 없는 완료를 선택해야 합니다. 날짜·시간 기본 항목을 앞에 배치하고 방문·미팅 등 별도 수행 시간과 추가 정보는 선택 영역으로 정리합니다. 캘린더용 실제 수행 시작·종료는 기존대로 함께 입력합니다.

수행자 표의 ‘수행 완료’ 열 제목은 ‘진행 상태’, ‘진행’은 ‘진행률’로 바꾸고 완료 상태에는 완료 시각을 함께 표시합니다.

## 시스템 로그

실제 수정은 바뀐 항목의 변경 전·후를 표로 비교합니다. 로그인·로그아웃·메일 발송 등은 ‘처리 결과’로 표시하고 빈 JSON을 노출하지 않습니다. 업무·직원 번호는 확인 가능한 업무명·직원명으로 표시합니다. 새 배정 메일 결과에는 이름·업무명의 발송 당시 스냅샷도 남깁니다. 저장된 과거 감사 기록은 변경하지 않습니다.

## 공지사항

- 알림 → 공지사항. 관리자는 전사·선택 부서·선택 직원을 대상으로 작성합니다. 이 버전의 작성·발송 관리는 관리자(is_superuser) 전용이며 일반 직원·서브 관리자에게 발송 권한을 추가하지 않습니다.
- 이메일·하이웍스 메신저 중 하나 또는 둘 다 선택합니다. 기존 회사 메일 및 하이웍스 알림 연결을 사용합니다.
- 작성 후 확인 화면에서 공지 내용·대상 명단·전달 방법·시각을 확인하고 최종 확정합니다. 작성 화면 저장만으로 발송하지 않습니다.
- 즉시·날짜/시간 예약 발송. 한국 시간 기준이며 서버가 약 15초 주기로 처리합니다. 처리 지연과 외부 서비스 상황에 따라 실제 수신 시각은 달라질 수 있습니다.
- 확정 당시 초대·이메일 인증 완료 직원의 명단을 보존합니다. 확정 뒤 입사·부서 이동은 대상에 자동 추가하지 않습니다. 발송 직전 재직·계정·메일 일치를 확인하며 재직 조회가 불가능하면 발송을 보류합니다.
- 예약 전에는 직원에게 보이지 않습니다. 게시된 공지는 대상 직원만 조회할 수 있습니다. 관리자는 전달 방법별 결과와 Workhub 공지 열람 시각을 확인합니다. 메일 접수 자체를 열람으로 표시하지 않습니다.
- 발송 시작 전 예약 취소 가능. 게시·발송 시작 후에는 취소/회수하지 못합니다. 결과가 불명확한 외부 요청은 자동 재발송하지 않습니다. ‘발송 접수’와 실제 수신은 구분합니다.
