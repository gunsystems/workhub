# v0.35.1 — 프로젝트 외부 처리와 저장 분리

- 프로젝트 생성·종료 사전 조회 및 Microsoft 처리 중에 SQLite 읽기 트랜잭션을 유지하지 않도록 변경.
- 외부 처리를 마친 후 실행 기록·프로젝트 상태·업무 문서 식별자를 짧은 로컬 트랜잭션으로 반영.
- 원격 권한 적용 후 로컬 확인 기록이 남지 않은 경우 현재 ACL을 조회해 정확히 일치하는 결과만 완료로 확인. 외부 권한 재적용 없음.
- 예외 종류와 발생 위치를 사용자 입력·토큰 없이 진단 로그에 기록.
- 외부 IO가 추가 SQL 트랜잭션 밖에서 실행되는지, 권한 확인이 외부 변경을 만들지 않는지 회귀 검사 추가.
