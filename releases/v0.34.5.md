# v0.34.5 — 업무 알림 최신순 통합

- 업무·개인 일정·업무협조·간단 업무·후속 조치·휴가·품의·서류 알림을 종류와 관계없이 하나의 최신순 목록으로 표시합니다.
- 각 알림의 업무·품의·신청 제목, 알림 내용, 종류와 수신 시각을 구분합니다. 개인 일정은 미래 예정 시간이 아닌 실제 알림 전달 시각으로 정렬합니다.
- 기존 수신자·접근 권한 필터, 읽음 처리 POST, 확인 링크와 종료된 후속 조치·휴가의 처리 제한을 유지합니다.
- 기존 종류별 최대 100개 조회 범위는 유지하며, 이미 생성된 기록을 변경하거나 새 알림을 발송하지 않습니다.
