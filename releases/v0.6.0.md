## 사용자에게 추가되는 기능

1. 업무 종류 기본 10종과 새 종류 추가. 프로젝트·종류·중요도·근무 형태를 구분.
2. 보고 업무와 간단 일정의 등록·공유 현황 통합. 실제 수행 시작/종료, 장소·고객사·예상시간·다음 조치 기록. 간단 일정은 결재 없이 수행 완료하고 업무 평가 산정에서 제외.
3. 대표 직원 계정의 사유 있는 직권 처리. 계정 운영 권한은 부여하지 않으며 본인 수행 업무의 직권 승인 차단.
4. 월/분기/주간 정기 업무 템플릿과 회차별 독립 업무. 일정 기준/완료 기준, 종료일·횟수, 미래 예정 확인·중지, 중복 방지와 담당/결재자 자격 확인.
5. 주간·기간 보고, 기존 업무 기록 선택, 지정 검토자 승인/보완, 직원 제출 버전을 연결한 취합, 제출 당시 상태 보존.
6. 보고서별 비공개 첨부. 파일당 10MB·최대 10개·제한된 형식, 권한 검사 다운로드. 공개 static 경로로 제공하지 않음.
7. 직원별 본인 수행 일정 iCal 구독 주소 발급/재발급/폐기. 회사 외부 전송 정책·계정/재직 자격 검사, 본문/첨부/개인메모/초안 제외, 앱 로그 토큰 마스킹.
8. 기존 Google 전송은 수행 시간이 있으면 그 시간으로, 없으면 마감일 종일 일정으로 전송. 동시간 겹침 안내와 기간 보고 검토 대기/반복 인계 알림 추가.

## 남은 범위 · 제한

- 템플릿 수정은 기존 반복 중지 후 변경한 새 업무에서 다시 설정. '이후 회차 일괄 수정' 전용 UI와 휴일 전후 영업일 이동은 후속 개발.
- 미래 예정은 반복 설정 화면에서 12회 미리보기. 아직 생성되지 않은 회차를 메인 달력에 겹쳐 표시하는 기능은 후속 개발.
- 주간 보고의 제출 기록 없음은 선택 기간과 겹치는 보고 유무이다. 보고 의무 템플릿/휴가/면제를 계산한 미제출 판정이 아님.
- 보고 전용 양식은 공통 결과·장애·다음 계획 및 기존 업무/체크리스트 연결 기반. 고객별 점검 양식 편집기는 후속 개발.
- 현재 한 업무에 수행 시간 구간 1개. 여러 시간대 블록·직원별 가용시간 대비 업무량·시간축 주간표는 후속 개발.
- 하이웍스 실제 개인 구독 성공·갱신 주기·수정/취소 반영은 공급자 화면에서 별도 확인 필요. 하이웍스 원본 직접 저장/양방향 편집이 아님.
- 일괄 이메일/메신저 주간보고 알림 및 복잡한 의존관계 자동 일정 조정은 포함하지 않음.

## 복구

기존 앱으로 롤백해도 신규 테이블/필드는 자동 삭제하지 않는다. 새 기능에서 생성한 업무는 일반 Task로 남으므로 롤백 버전에서도 기존 업무 권한과 이력을 보존해야 한다. DB 복원은 이후 작성 업무를 되돌릴 수 있어 코드 롤백과 구분한다. 외부 캘린더에 이미 수신된 내용은 서버 롤백만으로 회수되지 않는다.
