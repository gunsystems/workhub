# v0.34.0 · Teams 개인 업무·전자결재 알림 준비

- 개인 알림 연결, 수신/종류 선택, 관리자 연결·발송 현황과 회사 Teams 앱 설치 패키지.
- 업무/간단 업무 배정, 업무 보고·휴가·품의·서류 대기와 처리 결과를 독립 Teams outbox에 연결.
- 기존 Workhub 알림·하이웍스·메일 유지. 발송은 기본 비활성화. Microsoft 알림 전용 앱·Azure Bot·Teams 설치 및 대표 본인 수신 검증 후 활성화한다.
- 개인 채팅, 회사 테넌트, Microsoft JWT 서명·앱·키 채널 endorsement·service URL 검증. 10분 일회용 코드·기존 Microsoft 본인 연결 확인·중복 연결 차단.
- 발송 전 현재 접근·활성 계정·인증 이메일·현재 결재 차례 확인. 연결 해제·앱 제거·담당 변경·이미 처리된 항목·오래된 알림 제외.
- 불확실한 발송은 자동 재시도하지 않고 상태를 남긴다. Teams에는 간단한 안내와 Workhub 링크만 전달.
- 설정 절차: `docs/TEAMS_NOTIFICATIONS.md`. 실제 외부 수신 검증은 회사 Microsoft 설정 후 별도로 진행한다.
