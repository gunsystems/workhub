# v0.32.0 · 폴더 중심 접근 관리

- 실제 폴더만 표시하는 목록과 폴더별 접근 관리 버튼으로 진입 흐름을 교체한다. 폴더를 누르면 하위 목록, 접근 관리를 누르면 해당 폴더의 사용 그룹 설정으로 이동한다.
- 접근 관리에는 현재 연결된 그룹만 표시하고, 추가할 그룹은 별도 선택 상자에서 고른다. 보기·편집 선택과 변경 건수로 저장 전 상태를 표시한다. 관리자와 기타 접근 정보는 추가 설정으로 접는다.
- 목록의 새 폴더에서 생성 후 바로 해당 폴더의 접근 관리로 연결한다. 기존 단일 사용 확인·CSRF·외부 권한 검사와 생성 감사 로그를 유지한다.
- 권한 복사·그룹 변경의 서버 검증, 사전 검토, 동시 변경 검사와 관리자 보호는 유지한다. 폴더 목록에서는 전체 그룹·ACL 조회를 생략한다. DB migration 없음.

검증: Django 전체 882개·관련 101개 및 브라우저 동작 검사 통과. CI run 43989124345 / job 133724877607.

운영 18d98df5fa3ddfa6488042b21619519e0f7dc5bc / dep-dbtq3j142hec73alvclg live. 실제 폴더 목록, 그룹 추가, 편집 선택, 서버 검토 및 취소, 새 폴더 화면 진입 확인. 실제 업무 폴더 생성·권한 변경은 하지 않았다.
