# Workhub v0.7.0 업데이트

2026-11-09 · Asia/Seoul · 로컬 검증 완료 · 운영 배포 준비

## 업무 배정 메일

업무를 새로 발행하거나 신규 수행자를 지정할 때 검증된 회사 이메일로 업무 배정 알림을 예약합니다. 팀 배정은 포함된 수행자들에게 보내며 참조자·결재자만 지정한 사람에게 배정 메일을 보내지는 않습니다. 초안과 단순 내용 수정에는 배정 메일을 보내지 않습니다. 정기 업무 회차·업무 인계도 포함합니다.

메일 양식은 사용자가 확인한 GUNSYSTEMS/Workhub 회사 양식을 사용합니다. 업무명·담당 역할·마감일·배정자와 ‘배정된 업무 확인하기’ 버튼으로 구성하며 본문 전체나 첨부를 보내지 않습니다. HTML 버튼 뒤 실제 주소는 존재하며 일반 텍스트 대체 본문에는 접근 링크를 제공합니다.

업무 저장과 메일 예약은 같은 트랜잭션에 저장합니다. 기존 백그라운드 작업이 약 15초 주기로 대기 메일을 처리합니다. 동기화 등 다른 처리와 서비스 상태에 따라 실제 발송은 지연될 수 있습니다. 메일 서버 접수와 직원 메일함 도착은 구분합니다. 전송 직전에 재직·인증·현재 배정을 다시 확인합니다. 확인 불가 결과는 중복 방지를 위해 자동 재발송하지 않으며 관리자 로그에서 확인할 수 있습니다. 이전 업무의 메일은 소급 예약하지 않습니다.

## 30분 무활동 로그아웃

관리자를 포함한 로그인 세션에 적용합니다. 클릭·포인터 이동·스크롤·키 입력 등의 활동 사실만 서버에 알립니다. 입력값·키 내용은 수집하지 않습니다. 활동 전송은 최대 15초 단위로 반영하므로 판정은 이 간격의 오차가 있을 수 있습니다. 백그라운드 조회나 캘린더 동기화는 세션을 연장하지 않습니다. 서버가 만료를 판정하므로 스크립트를 끄거나 오래된 페이지를 제출해도 권한이 복원되지 않습니다. 다른 탭의 활동도 같은 로그인 세션에서 공유합니다.

아직 저장하지 않은 입력 내용은 자동 저장되지 않습니다. 로그아웃 후에는 다시 비밀번호·OTP 인증해야 합니다.

## 관리자 시스템 로그

관리자 전용 → 시스템 로그에서 기간·작업·처리자로 검색하고 변경 전후를 확인합니다. 업무·프로젝트·직원·부서·업무 요청·결재·체크리스트·기간 보고 등의 생성/수정/삭제, 업무 처리, 로그인/로그아웃/무활동 만료와 배정 메일 결과를 보존합니다. 업무 처리 로그에는 수행자·결재라인을 함께 기록합니다. 별도 로그 변경/삭제 UI는 제공하지 않습니다.

개인 보드의 제목·메모·태그·개인 일정 내용, 비공개 초안 본문, 비밀번호·OTP·인증 토큰은 기록하지 않습니다. 개인 항목은 변경 사실만 남깁니다. 로그 자체는 DB 운영자가 조작할 수 없는 외부 보안 저장소가 아니며, 직접 DB 수정·관리 스크립트의 모든 변경을 감시하는 DB 감사 기능도 아닙니다. 기존 데이터의 과거 로그는 소급 생성하지 않습니다. 로그 조회는 복원 기능이 아니므로 백업은 별도로 보관해야 합니다.
