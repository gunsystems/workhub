# v0.23.0 · 품의 작성·증빙·품목별 합산

- 품의 작성 화면에서 최대 10개 파일(각 20MB)과 참고·증빙 링크를 첨부할 수 있습니다. 저장 후 상세 화면의 자료 추가 방식도 유지합니다.
- 품목·수량·부가세 포함 단가를 표로 입력하고 행별 금액과 총 요청 금액을 합산합니다. 서버가 입력을 재검증하고 원 단위 반올림 후 합산합니다. 최대 50행이며 기존 총액 입력 품의는 그대로 유지됩니다.
- 결재 제출과 임시 저장을 구분합니다. 제출 전 상태를 명시하고 결재함에서 품의 목록으로 안내합니다.
- 제출된 품의는 직원 본인, 팀장 소속 팀, 대표·본부장 전사, 시스템 관리자 전체 범위로 조회합니다. 미제출 초안은 작성자·관리자만 열람합니다. 조회 권한으로 결재 권한을 부여하지 않습니다.
- 전자결재 메뉴를 휴가 / 품의 / 결재함 / 처리 내역으로 분류합니다. 휴가 전용 내역은 휴가 하위에 둡니다.
- 품의 자료함 명칭을 참고·증빙자료, 추가 버튼을 증빙자료 추가로 정리합니다. 제출된 자료에는 보관 버튼을 표시하지 않습니다.
- 품목 내역을 제출·처리 스냅샷에 보존합니다. 기존 사용자 초안과 결재 데이터는 변경하지 않습니다.

## 검증

품의 집중 검사 17개 통과, 품목 계산 Node 검사 통과. 전체 회귀 검사·배포·실제 화면 확인은 진행 중입니다. 운영 사용자 품의 제출·승인·첨부는 대신 실행하지 않습니다.

## 저장소 제약

파일 저장은 기존 비공개 Drive 저장소를 사용합니다. 외부 파일 저장과 DB는 분산 트랜잭션이 아니므로 전송 도중 실패한 파일은 DB에 연결되지 않은 원본이 남을 수 있습니다. 사용자에게 성공으로 표시하지 않으며 재선택을 안내합니다.
