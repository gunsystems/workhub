# v0.18.3 공식 공휴일 자동 갱신

- 공공데이터포털 한국천문연구원 특일 정보 getRestDeInfo API를 사용합니다. 날짜 계산 라이브러리나 비공식 달력으로 대체하지 않습니다.
- 현 연도·다음 연도를 매일 조회하며, 연도가 바뀌면 다음 해도 자동 준비합니다. 추가 연도는 관리자 갱신 요청으로 등록할 수 있습니다.
- 12개월 모두 성공하고 건수·날짜·휴일 여부·필수 공휴일을 확인한 뒤 한 트랜잭션으로 교체합니다. 미공개·빈 자료·오류·부분 응답은 기존 공휴일을 지우지 않습니다. 오류는 1시간 후 재시도합니다.
- 업무 캘린더 월·주·일 보기에 공식 공휴일명과 회사 휴일을 표시합니다. 업무 건수와 수행 상태에는 포함하지 않습니다.
- 회사 지정 휴일은 별도 테이블로 유지합니다. 공식 공휴일과 겹쳐도 이중 차감하지 않습니다. 토·일요일은 기존처럼 제외합니다.
- 휴무일 변경이 대기·승인·취소 결재 중 신청과 겹치면 재검토로 표시합니다. 관리자가 전후 일수를 확인·반영하며, 승인 건은 차액 원장을 남깁니다. 대기 건은 실제 사용일이 바뀌면 재결재하고, 전부 휴일이면 회수합니다. 중복 반영·중복 차감은 막습니다.
- 초기 인증키 미설정, 마지막 성공 시각, 조회 실패 상태를 관리자 화면에 표시합니다. 공식 자료가 48시간 이상 확인되지 않으면 새 신청·승인을 차단해 오래된 달력으로 차감하지 않게 합니다.
- 자동 갱신은 별도 스케줄러 스레드에서 실행해 로그인·기존 알림 작업을 막지 않습니다. 연도별 DB 임대로 중복 수집을 방지합니다. API 키나 원본 예외 URL을 로그·DB에 기록하지 않습니다.
- 휴가 기능은 관리자 미리보기만 유지합니다. 직원 공개·자동 연차 부여·출근율 판정은 변경하지 않습니다.

## 최초 연결

공공데이터포털에서 한국천문연구원 특일 정보 활용 신청 후 Render 환경 변수 KASI_SERVICE_KEY에 일반 인증키(Decoding)를 등록합니다. 키는 채팅·Git에 기록하지 않습니다. 해당 포털의 활용 기간 만료 전 연장 신청이 필요합니다.

## 출처

- API: https://apis.data.go.kr/B090041/openapi/service/SpcdeInfoService/getRestDeInfo
- 2026년 공휴일 변경 확인: https://www.moel.go.kr/news/enews/report/enewsView.do?news_seq=19254

## 마이그레이션과 롤백

0046_public_holiday_sync는 PublicHoliday, HolidaySync, LeaveCalendarReview 테이블만 추가합니다. 기존 회사 휴무일·연차 원장은 보존합니다. 코드 롤백 시 추가 테이블을 삭제하지 않습니다. 이전 버전은 공식 공휴일 테이블을 참조하지 않으므로 휴가 운영을 열기 전 버전으로 롤백할 때 직원 공개 차단 상태를 유지해야 합니다.
