# v0.32.2 · 폴더 권한 현황 즉시 표시와 이름 연결

- 관리자별·Microsoft 연결별로 완전 조회된 현황만 DB에 저장하고 화면에서 즉시 표시한다. 마지막 동기화 시각, 진행·오류 상태, 지금 동기화를 제공한다. 현황 저장은 파일 접근 허용 판단에 사용하지 않는다.
- 별도 스케줄러 작업이 15분마다 갱신한다. Workhub 폴더·권한·그룹 변경은 해당 사이트의 현황을 갱신 대기로 표시한다. 조회 중 변경 리비전이 달라지면 결과를 채택하지 않고 다시 조회한다.
- 오류·부분 조회 시 마지막 완전 현황을 보존한다. 작업 잠금과 완료 fencing으로 중복 실행·오래된 결과 덮어쓰기를 막는다. 관리자 역할·사이트·테넌트·앱·연결 계정/연결 시점이 바뀌면 이전 현황을 노출하지 않는다.
- 회사 직원 디렉터리의 정확한 이메일 매칭으로 이름을 표시한다. 다른 로그인 주소는 관리자가 명시적으로 직원 이름에 연결하며, 원래 Microsoft 계정이나 실제 접근 권한을 바꾸지 않는다. 같은 이름·이메일 앞부분으로 추측하지 않는다.
