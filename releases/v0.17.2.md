# v0.17.2 관리자 전용 일정·업무 휴지통

- 관리자 및 이메일 인증·OTP 등록을 마친 서브 관리자만 삭제·복구할 수 있습니다. 대표·본부장·팀장 등 업무 권한만으로는 사용할 수 없습니다.
- 업무 상세의 관리자 전용 ‘일정 · 업무 삭제’에서 사유와 확인 팝업을 거쳐 휴지통으로 이동합니다. 관리자 메뉴와 업무 현황의 휴지통에서 복구합니다.
- 일반 업무 조회·캘린더·하이웍스 iCalendar 구독 데이터에서 제외합니다. 삭제자·시각·사유 및 복구 이력을 시스템 로그에 남깁니다.
- Google에 등록된 일정은 기존 동기화가 DELETE 요청을 처리합니다. 복구 후에는 새 이벤트 식별자를 사용합니다.
- 관련 문서·첨부·배정·보고·결재·의견·제출 스냅샷은 보존합니다. 파일을 지우거나 원본 업무를 영구 삭제하지 않습니다.
- 삭제 업무를 템플릿으로 사용하는 정기 업무 생성은 중지합니다. 복구해도 자동 재개하지 않습니다. 이미 생성된 다른 회차는 삭제하지 않습니다.
- 마이그레이션0043은 DB 기본값 false인 삭제 표시와 휴지통 기록 테이블을 추가합니다. 기존 업무는 변경하지 않습니다. 예전 버전으로 코드 롤백하면 삭제 항목이 취소 상태로 다시 보일 수 있습니다.

- 보고 관련 버튼·제목·도움말을 주간업무보고 작성 / 업무보고 작성 / 업무보고 제출로 통일하고 다른 보고 작성 버튼을 다른 업무보고 작성으로 변경합니다.

## 확인 방법
1. 관리자 계정으로 테스트 업무 상세 → 일정 · 업무 삭제를 선택합니다.
2. 삭제 사유를 입력하고 휴지통 이동을 확정합니다.
3. Workhub 업무 목록·캘린더에서 제외되는지 확인합니다.
4. 하이웍스 구독 갱신 후 일정이 사라지는지는 사용자가 직접 확인합니다. Workhub는 해당 UID를 더 이상 내보내지 않으며, 외부 서비스의 실제 삭제 표시 및 갱신 시각은 보장하지 않습니다.
5. 관리자 휴지통에서 복구하면 이전 상태로 돌아갑니다.

## 범위
- 대상은 업무 현황·업무 캘린더에 등록된 업무입니다. 개인 보드의 기존 카드 휴지통과 간단 업무는 변경하지 않습니다.
- 실제 테스트 일정의 삭제·복구는 사용자가 선택해 진행합니다. 배포 과정에서 실제 업무를 임의 삭제하지 않습니다.
