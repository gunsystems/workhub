# v0.20.1 · 전자결재 대기 건수

- 왼쪽 전자결재 메뉴 오른쪽에 로그인한 본인의 현재 결재 대기 건수 표시. 0건이면 숨김.
- 앞 결재 차례·이미 처리한 신청 제외. 취소 신청은 최신 결재 회차 기준으로 포함.
- 메뉴 숫자는 조회 연도와 관계없이 전체 대기 건수. 관리자 미리보기에서 선택한 직원으로 메뉴 숫자가 바뀌지 않음.
- 결재함과 메뉴가 같은 전체 연도 조회 규칙 사용. 기존 관리자 미리보기 공개 범위 유지.
- 화면 이동 또는 새로고침 시 갱신. 실시간 자동 갱신은 제공하지 않음. 메일 알림은 아래와 같이 별도 준비.
- 실제 휴가·연차 데이터 변경 없음. 알림 outbox용 0050 마이그레이션 추가.

- 결재 요청 및 신청자 최종 결과 메일·업무 알림 outbox 준비. 미리보기에서는 기본 비활성화. 정식 직원 공개와 함께 별도 활성화 필요.
- 메일은 HTML 회사 양식과 결재/결과 확인 버튼 제공. 신청 사유는 메일에 포함하지 않음.
- 중복 발송 방지, 오래된 결재 요청 건 발송 제외, 수신 계정·인증 이메일 재확인. 네트워크 결과 불명은 자동 재발송하지 않고 시스템 로그에 기록.
- 임원/팀장 미리보기의 휴가 현황에 조회 범위 내 직원별 연차 요약 추가. 조정 버튼은 제공하지 않음.
