# v0.34.7 — 표준 공동문서 구조 정책과 관리자 적용 예정 조회

- 2026-11-20 명세서의 고정 폴더 51개와 여섯 벤더 위치를 코드 정책으로 정의합니다.
- 진행·완료 프로젝트의 그룹 단위 권한, 승인된 완료 프로젝트 루트의 추가 상속 경계와 4단계 예외를 정의합니다.
- 프로젝트 이름·금지 문자·40자 제한과 기존 경로 충돌을 검증합니다.
- 관리자 전용 적용 예정 화면은 연결 범위가 일치하는 완료된 폴더 현황을 조회합니다. 오래된 현황은 시각을 명시하며 실제 권한 판단에 사용하지 않습니다.
- 기존 ‘전사 공통’과 새 ‘전사공통’을 구분합니다. 조회 기능에는 SharePoint 변경 동작이 없습니다.
- 이 릴리스는 준비 단계입니다. 실제 폴더 생성·권한 적용·프로젝트 생성/이관·권한 요청 기능의 완성을 의미하지 않습니다.

검증: 구조·매트릭스·충돌·레거시 보존·관리자/직원 접근·연결 변경·POST 차단 및 기존 그룹/현황 검사 78개 통과.
