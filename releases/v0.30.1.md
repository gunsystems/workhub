# v0.30.1 문서 그룹 권한 관리 운영 반영

상태: 운영 반영 및 실제 기능 검증 완료. 모바일 실화면 검증은 별도 미완료.

## 변경
- 폴더 트리와 그룹별 권한 표, 그룹 구성원 검색·부서 필터·다중 선택, 직원별 선택 폴더 유효 권한 조회.
- SharePoint REST로 권한 조회·변경 및 명시적인 상속 해제·복원. 기존 개인·다른 그룹·소유자 권한 보존.
- 상속 해제 후 SharePoint가 관리하는 제한된 접근과 표시 정보 차이로 발생한 결과 경고 보완. 실제 대상 ID·유형·권한 ID 보존 검사는 유지.
- 문서함 root 제목을 문서함 이름으로 표시, 조회 버튼 정렬 및 빈 그룹 생성 설명 보완.
