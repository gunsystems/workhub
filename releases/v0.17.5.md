- 작성·배포 전 검토·응답·결과·목록 화면의 문장, 질문, 선택지, 안내문 간격 정리.

- 설문·공지 관련 기존 검사 34개 통과. 초기 로컬 검사는 신규 CSS 정적 파일 수집 전 오류였으며 collectstatic 후 정상 통과.
