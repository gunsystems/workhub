# v0.26.3 · 문서함 경로 조회 추가 최적화

- v0.26.2 실제 브라우저 이동은 문서함 약 2.6초, 하위 폴더 약 3.2초로 대기가 남아 추가 개선.
- 같은 Microsoft 사용자 토큰과 설정에 한해 확인한 사이트 URL→ID 매핑을 최대 5분 재사용. 문서함 목록·접근 허용 결과·문서 내용은 저장하지 않으며 사용자별 Graph 요청으로 매번 확인.
- 현재 폴더의 검증된 상위 경로가 문서함 루트임을 나타내면 경로 표시만을 위한 루트 조회를 생략.
- 권한 회수·문서함 목록 변경·사용자 토큰 격리 및 루트 경로 조회 횟수 검사 추가.
- 배포 후 로그인 계정으로 실제 응답시간 재확인 예정. 네트워크 및 Microsoft 응답에 따라 속도는 달라질 수 있음.
