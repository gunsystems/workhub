퇴사 후속 조치

관리자가 항목별 담당자와 기한을 정하고 실제 처리 증빙을 검토합니다.

한눈에 보는 흐름

이렇게 사용하세요

  1. 관리자는 직원 관리 → 퇴사 후속 조치에서 퇴사 직원을 등록합니다. 기본 항목은 관리자에게 배정되며 항목별 담당자·기한을 변경할 수 있습니다.
  2. 담당자는 배정된 후속 조치 또는 업무 알림에서 본인 항목을 엽니다. 외부 서비스에서 직접 처리한 뒤 실제 처리 일시·내용과 이미지/PDF 증빙을 제출합니다.
  3. 제출하면 확인 대기로 바뀝니다. 관리자가 증빙을 보고 확인 완료 또는 사유를 적어 보완 요청합니다. 재제출해도 이전 증빙과 검토 이력은 남습니다.
  4. 모든 항목의 확인이 끝나면 관리자가 퇴사 처리 최종 완료를 누릅니다. 해당하지 않는 항목은 관리자가 사유와 함께 해당 없음으로 확인합니다.

알아두세요

  • 외부 계정 삭제·로그인 중지·라이선스 회수는 자동 실행하지 않습니다. Workhub 계정 중지도 계정 관리에서 별도 처리해야 합니다.
  • 직원은 배정된 항목만 보며 전체 퇴사 건·다른 담당자의 증빙은 볼 수 없습니다. 증빙은 공개 링크로 공유하지 않습니다.
  • 처리 기한이 임박하거나 지나면 담당자에게, 증빙 확인이 남으면 관리자에게 업무 알림과 이메일을 보냅니다. 지연·확인 대기는 화면에서도 구분됩니다.
  • 퇴사일 변경 후 항목별 기한은 별도로 조정하세요. 퇴사 처리 취소는 외부 시스템의 변경을 되돌리지 않습니다.
  • 비밀번호·인증키와 다른 직원의 개인정보는 증빙에서 가려 주세요.
