  1. Workhub에서 연결 주소 복사

    본인 직원 계정으로 ‘하이웍스 일정 연결’을 열고 연결 주소를 발급해 복사합니다. 주소를 잃어버린 경우에만 재발급하세요. 재발급하면 이전 주소는 사용할 수 없습니다.

  2. 하이웍스에서 내 캘린더 찾기

    하이웍스의 ‘일정’을 열고 왼쪽의 내 캘린더 줄에 마우스를 올립니다. 오른쪽에 나타나는 ⊕ 버튼을 누른 뒤 외부 캘린더 구독하기를 선택합니다. 맨 위의 ‘일정 추가’ 버튼과 다릅니다.

  3. 아래 입력창에서 주소와 이름 설정

    URL 추가에 복사한 주소를 붙여 넣고 캘린더 이름을 Workhub로 입력합니다. 색상과 알림은 원하는 값으로 선택한 뒤 저장을 누릅니다.

  4. 캘린더 표시 확인

    왼쪽 내 캘린더에 추가된 Workhub가 체크되어 있는지 확인합니다. 업무가 있는 날짜로 이동해 일정 표시를 확인하세요. 수정·취소는 Workhub에서 하며 하이웍스의 구독 갱신에 따라 반영됩니다.
