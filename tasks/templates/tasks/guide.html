① 프로젝트 등록 · 관리자

프로젝트에서 목표·담당 부서·총괄 담당자·기간을 지정합니다. 프로젝트 총괄 담당자로 연결된 부서 관리자 또는 최상위 관리자가 프로젝트를 수정할 수 있습니다.

② 업무 요청 접수 · 직원

업무 접수함 → 요청 접수에서 제목·처리 부서·프로젝트·희망 마감일·요청 내용을 입력합니다. 담당자가 정해지지 않았어도 요청을 먼저 남깁니다.

③ 요청을 업무로 배정 · 관리자

접수함의 요청을 열어 ‘담당자 지정 · 업무 배정’을 누릅니다. 담당 직원, 우선순위, 완료 조건, 보고 주기, 검토 기한을 지정합니다. 업무 기간은 프로젝트 기간 안으로 지정하세요. 배정 전 요청은 접수함에 남습니다.

④ 배정 확인 · 직원

내 업무에서 배정 업무를 열어 ‘배정 확인’을 누릅니다. 보고부터 시작해도 배정 확인 이력이 자동으로 남습니다.

⑤ 체크리스트 · 진행 보고

업무 상세에 필수 확인 항목을 추가하고 직원 계정으로 처리합니다. ‘진행 보고’에는 진행률, 수행 내용, 다음 계획, 지연·장애 사유를 남깁니다. 관리자 피드백만으로 직원의 보고 누락이 해소되지는 않습니다.

⑥ 완료 보고 · 검토

필수 항목을 남긴 채 완료 보고하면 차단되는지 확인하세요. 필수 항목을 모두 확인하고 결과를 보고한 뒤, 관리자 계정으로 승인하거나 보완 요청합니다. 본인 업무는 스스로 승인할 수 없습니다.

⑦ 전체 상황 확인

프로젝트에서 업무별 진행·지연·장애 요인을, 조치 필요 알림에서 미확인 배정·미배정 요청·마감·미보고·검토 지연을 확인하세요. 관리 화면에서는 직원별 업무량과 관리 필요 항목을 확인할 수 있습니다.

테스트 시 알아둘 점

알림은 사이트 화면을 열 때 갱신되는 조치 목록입니다. 이메일·메신저·브라우저 푸시는 발송하지 않습니다. 날짜와 주기는 한국 시간, 달력 일수 기준입니다. 프로젝트 진행률은 연결 업무의 단순 평균이며, 검토 대기 업무는 진행률이 100%여도 승인 완료 건수에 포함되지 않습니다. 과거 완료 시점을 모르는 업무는 평가 점수를 만들지 않습니다.

현재 버전은 화면 아래 ‘Workhub v0.3’ 또는 버전 확인에서 확인하세요. 예시 데이터는 실제 업무로 사용하지 마세요.
