# Workhub product guidance

- Employee-facing screens and help explain the employee's actions, workflow and meaningful limitations in plain Korean.
- Show administrator setup, permission administration and operational instructions only to the roles that perform those tasks, using server-side role checks. Keep business management roles distinct from system administration.
- Do not include development status, test instructions or implementation details in employee guidance. Put those in development/release documentation.
- On first-use screens, explain the purpose, where to start and the result of an action. Do not rely on a help dialog alone for essential onboarding.
- Keep shared document access explanations actionable: tell users when to contact the administrator; do not tell ordinary employees to configure SharePoint permissions.
